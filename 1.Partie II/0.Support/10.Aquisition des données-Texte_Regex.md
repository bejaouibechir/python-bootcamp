# 6. Assertions : Anchors

## 6.1 Début et fin de ligne

Créer le fichier anchors_demo.py :

```python
"""
Objectif :
Comprendre les anchors ^ et $
pour cibler début et fin de chaîne.
"""

import re

texte = "Python est puissant"

# Mot au début
pattern_debut = r"^\w+"

resultat = re.search(pattern_debut, texte)

print("Début :", resultat.group())

# Mot à la fin
pattern_fin = r"\w+$"

resultat = re.search(pattern_fin, texte)

print("Fin :", resultat.group())
```

Applications métier :

- Vérifier qu’un identifiant commence par une lettre

- Vérifier qu’un fichier finit par .csv

- le nom

# 10. finditer vs findall

"""
Objectif :
Comparer findall et finditer.
finditer permet un contrôle plus fin.
"""

import re

texte = "IPython IPython Python"

pattern = r"IPython"

for match in re.finditer(pattern, texte):
    print("Match :", match.group())

Avantage :

- Accès aux positions

- Utile pour annotation de texte

# 11. Compilation des regex

Créer le fichier compile_demo.py :

```python
"""
Objectif :
Compiler une regex pour réutilisation performante.
Recommandé dans les boucles ou systèmes intensifs.
"""

import re

patterns = [re.compile(p, re.IGNORECASE) for p in ["un", "deux", "trois"]]

texte = "J'ai Un lapin, Deux poules et trois dindons"

for regex in patterns:
    if regex.search(texte):
        print("Trouvé :", regex.pattern)
    else:
        print("Non trouvé :", regex.pattern)
```

Bonne pratique :

- Compiler si usage répété

- Utiliser des flags

- Centraliser les patterns

# 1) Pourquoi utiliser raw string r"..." en regex ?

## Énoncé

Que se passe-t-il si on oublie le préfixe r dans une regex contenant \d ou \n ?

## Solution

```python
"""
Explication :
En Python, le caractère \ est aussi utilisé pour les séquences d'échappement.
Exemple : \n signifie retour à la ligne.
Donc "\d" peut être interprété incorrectement.

La raw string r"\d+" empêche Python d'interpréter les backslashes.
C’est une bonne pratique systématique en regex.
"""

import re

texte = "abc123"

# Mauvaise pratique
pattern_mauvais = "\d+"

# Bonne pratique
pattern_bon = r"\d+"

print("Sans raw string :", re.findall(pattern_mauvais, texte))
print("Avec raw string :", re.findall(pattern_bon, texte))
```

# 3) Pourquoi . est dangereux ?

## Énoncé

Pourquoi le point peut provoquer des correspondances inattendues ?

## Solution

```python
"""
Explication :
Le point signifie "n'importe quel caractère sauf saut de ligne".
Donc dans une adresse email, . doit être échappé avec \.
"""

import re

texte = "test@gmailxcom"

pattern_mauvais = r"gmail.com"
pattern_bon = r"gmail\.com"

print("Sans échappement :", re.search(pattern_mauvais, texte))
print("Avec échappement :", re.search(pattern_bon, texte))
```

# 4) Greedy vs Non-greedy

## Énoncé

Pourquoi .* capture parfois trop de texte ?

## Solution

```python
"""
Explication :
.* est gourmand (greedy) → capture le maximum possible.
.*? est non gourmand → capture le minimum.
"""

import re

texte = "<div>contenu1</div><div>contenu2</div>"

pattern_greedy = r"<div>.*</div>"
pattern_lazy = r"<div>.*?</div>"

print("Greedy :", re.findall(pattern_greedy, texte))
print("Lazy :", re.findall(pattern_lazy, texte))
```

# 8) Comment nommer les groupes ?

## Énoncé

Comment rendre la regex plus lisible ?

## Solution

```python
"""
Explication :
Les groupes nommés améliorent la lisibilité.
On utilise ?P<nom>.
"""

import re

texte = "bechir@gmail.com"

pattern = r"(?P<user>[A-Za-z]+)@(?P<domain>[A-Za-z]+)\.(?P<ext>[a-z]+)"

match = re.search(pattern, texte)

print("Utilisateur :", match.group("user"))
print("Domaine :", match.group("domain"))
print("Extension :", match.group("ext"))
```

# 20) Comment construire un analyseur simple complet ?

## Énoncé

Lire un texte, extraire emails, compter domaines.

## Solution

```python
"""
Explication :
Script complet combinant lecture, compilation,
extraction, structuration et affichage.
"""

import re
from collections import Counter

with open("emails.txt", "r", encoding="utf-8") as file:
    content = file.read()

pattern = re.compile(r"([A-Za-z]+)@([A-Za-z]+)\.(fr|com|ch)", re.IGNORECASE)

domaines = []

for match in pattern.finditer(content):
    utilisateur = match.group(1)
    domaine = match.group(2)
    extension = match.group(3)

    print("Utilisateur :", utilisateur)
    print("Domaine :", domaine)
    print("Extension :", extension)
    print("-" * 20)

    domaines.append(domaine)

statistiques = Counter(domaines)

print("Résumé statistique :", statistiques)
```
