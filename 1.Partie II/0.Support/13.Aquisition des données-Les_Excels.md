# 2. Lecture d’un fichier Excel avec openpyxl

## 2.1 Objectif

Charger un fichier Excel et accéder à une cellule spécifique.

---

## Script : lecture d’une cellule

```python
"""
Objectif :
- Charger un fichier Excel
- Accéder à la feuille active
- Lire la valeur d’une cellule précise

Cas métier :
Lire le nom de la première colonne d’un export assurance.
"""

from openpyxl import load_workbook

# Chemin du fichier Excel
path = 'C:\\temp\\io\\FL_insurance_sample.xlsx'

# Chargement du classeur
wb = load_workbook(path)

# Accès à la feuille active
feuille = wb.active

# Accès à la cellule ligne 1, colonne 1
cellule = feuille.cell(row=1, column=1)

# Affichage de la valeur
print(cellule.value)
```

Sortie attendue :

policyID

---

## Point technique important

La méthode cell(row, column) est indexée à partir de 1, pas 0.

# 5. Lecture avec xlrd

## Contexte

xlrd était historiquement utilisé pour lire les fichiers Excel.  
Depuis les versions récentes, il ne supporte plus .xlsx sans version spécifique.

---

## Lecture simple

```python
"""
Objectif :
- Lire les 10 premières lignes
- Accéder aux cellules via index

Note :
Indexation à partir de 0
"""

from xlrd import open_workbook

path = 'C:\\temp\\io\\FL_insurance_sample.xlsx'

wb = open_workbook(path)
feuille = wb.sheet_by_index(0)

for r in range(0, 10):

    cell1 = feuille.cell_value(r, 0)
    cell2 = feuille.cell_value(r, 1)
    cell3 = feuille.cell_value(r, 2)

    print(f'{cell1} {cell2} {cell3}')
```

### Fichier input

```python
Génère un fichier volumineux pour comparer lecture normale vs read_only.

wb = Workbook()
ws = wb.active
ws.append(["id", "statecode", "amount"])

    ws.append([i, "FL" if i % 2 == 0 else "TX", i * 0.5])

wb.save(xlsx_path)

print("Créé :", xlsx_path)
```

### Démo

Créer le fichier **q04_demo.py** :

```python
"""
But :
- Comparer le temps de parcours des lignes
- Montrer iter_rows(values_only=True) en read_only

À exécuter :
- python q04_make_input.py
- python q04_demo.py
"""

from pathlib import Path
import time
from openpyxl import load_workbook

xlsx_path = Path("data") / "q04_readonly.xlsx"

t0 = time.time()
wb1 = load_workbook(xlsx_path, read_only=False)
ws1 = wb1.active
s = 0
for row in ws1.iter_rows(min_row=2, values_only=True):
    s += row[0]
t1 = time.time()

t2 = time.time()
wb2 = load_workbook(xlsx_path, read_only=True)
ws2 = wb2.active
s2 = 0
for row in ws2.iter_rows(min_row=2, values_only=True):
    s2 += row[0]
t3 = time.time()

print("Somme contrôle :", s, s2)
print("Normal (s) :", round(t1 - t0, 4))
print("Read_only (s) :", round(t3 - t2, 4))
```

```python
But :
- Nettoyer les en-têtes
- Rendre les noms cohérents et uniques

- python q11_make_input.py
- python q11_demo.py

clean = []
seen = {}

    if c in seen:
        seen[c] += 1
        c = f"{c}_{seen[c]}"
    else:
        seen[c] = 0
    clean.append(c)

df.columns = clean

print("Après :", list(df.columns))
print(df.head())
```

```python
"""
Génère deux fichiers Excel proches, avec une différence à détecter.
"""

from pathlib import Path
from openpyxl import Workbook

out_dir = Path("data")
out_dir.mkdir(exist_ok=True)

def make_file(p, rows):
    wb = Workbook()
    ws = wb.active
    ws.append(["id", "value"])
    for r in rows:
        ws.append(r)
    wb.save(p)
    print("Créé :", p)

make_file(out_dir / "q19_v1.xlsx", [(1, "A"), (2, "B"), (3, "C")])
make_file(out_dir / "q19_v2.xlsx", [(1, "A"), (2, "B2"), (4, "D")])
```

### Démo

```python
"""
But :
- Comparer v1 et v2 sur la clé id
- Afficher ajoutés, supprimés, modifiés

À exécuter :
- python q19_make_input.py
- python q19_demo.py
"""

from pathlib import Path
import pandas as pd

v1 = pd.read_excel(Path("data") / "q19_v1.xlsx")
v2 = pd.read_excel(Path("data") / "q19_v2.xlsx")

m1 = v1.set_index("id")
m2 = v2.set_index("id")

added = m2.loc[m2.index.difference(m1.index)]
removed = m1.loc[m1.index.difference(m2.index)]

common = m1.index.intersection(m2.index)
changed = common[m1.loc[common, "value"] != m2.loc[common, "value"]]

print("Ajoutés :")
print(added)

print("Supprimés :")
print(removed)

print("Modifiés :")
for i in changed:
    print("id", i, ":", m1.loc[i, "value"], "->", m2.loc[i, "value"])
```

### Démo

Créer le fichier **q20_demo.py** :

```python
"""
But :
- Vérifier existence fichier
- Valider schéma
- Nettoyer (policyID non nul, doublons)
- Exporter
- Relire pour contrôler

À exécuter :
- python q20_make_input.py
- python q20_demo.py
"""

from pathlib import Path
import pandas as pd

inp = Path("data") / "q20_pipeline.xlsx"
outp = Path("data") / "q20_pipeline_clean.xlsx"

required = {"policyID", "statecode", "county"}

if not inp.exists():
    raise FileNotFoundError("Fichier input introuvable")

df = pd.read_excel(inp)

missing = required - set(df.columns)
if missing:
    raise ValueError("Schéma invalide, colonnes manquantes : " + ", ".join(sorted(missing)))

before = len(df)

df = df.dropna(subset=["policyID"])
df = df.drop_duplicates()

after = len(df)

df.to_excel(outp, index=False)

check = pd.read_excel(outp)

print("Avant nettoyage :", before)
print("Après nettoyage :", after)
print("Sortie :", outp)
```
