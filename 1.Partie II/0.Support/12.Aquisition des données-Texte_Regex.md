# 1️⃣ Pourquoi les expressions régulières ?

Imaginez un fichier de logs avec des milliers de lignes. Vous cherchez tous les emails, tous les codes erreur, toutes les versions. Faire ça avec des méthodes Python classiques est possible — mais fastidieux. Les **expressions régulières** (regex) sont faites exactement pour ça.

**Sans regex — les limites :**

```python
texte = "Contact : bechir@gmail.com ou sarra@yahoo.fr pour infos"

# Approche naïve : split + conditions
mots = texte.split()
emails_trouves = []

for mot in mots:
    if "@" in mot:
        emails_trouves.append(mot)

print(emails_trouves)
```

```
['bechir@gmail.com', 'sarra@yahoo.fr']
```

Ça marche ici — mais échouera dès que le texte change légèrement :

```python
texte2 = "Contact:bechir@gmail.com, sarra@yahoo.fr."
# split(" ") → ['Contact:bechir@gmail.com,', 'sarra@yahoo.fr.']
# Les emails sont corrompus (virgule, point collés)
```

- **`split(" ")`** découpe sur les espaces — échoue si la ponctuation est collée
- **aucune validation** : on accepte `n'importe@quoi` s'il contient `@`
- **pas scalable** : pour des emails + numéros + codes + dates, il faudrait des dizaines de conditions
- **la solution** : une regex décrit un **motif** — Python trouve toutes les chaînes qui correspondent, peu importe le contexte

# 2️⃣ Introduction au module `re`

Le module `re` est le couteau suisse des regex en Python. Quatre fonctions couvrent 90% des besoins.

```python
import re

texte = "Commande CMD-001 validée le 12/03/2025, montant : 149.90 TND"

# ── re.search() : trouve la PREMIÈRE occurrence ───────────────────────────
match = re.search(r"\d+\.\d+", texte)   # cherche un nombre décimal
if match:
    print("Montant :", match.group())    # 149.90

# ── re.findall() : trouve TOUTES les occurrences ──────────────────────────
tous_les_chiffres = re.findall(r"\d+", texte)
print("Tous les nombres :", tous_les_chiffres)   # ['001', '12', '03', '2025', '149', '90']

# ── re.match() : teste uniquement le DÉBUT de la chaîne ──────────────────
print(re.match(r"Commande", texte))    # <Match object> ✅
print(re.match(r"CMD",      texte))    # None ❌ — "CMD" n'est pas au début

# ── re.sub() : REMPLACER des occurrences ─────────────────────────────────
anonymise = re.sub(r"CMD-\d+", "CMD-XXX", texte)
print(anonymise)   # Commande CMD-XXX validée...
```

```
Montant : 149.90
Tous les nombres : ['001', '12', '03', '2025', '149', '90']
None
Commande CMD-XXX validée le 12/03/2025, montant : 149.90 TND
```

- **`r"..."`** : raw string — le `\` n'est pas interprété par Python → `\d` reste `\d` et n'est pas converti en caractère spécial
- **`re.search()`** : retourne un **Match object** ou `None` — toujours vérifier avant d'appeler `.group()`
- **`re.findall()`** : retourne une **liste** de chaînes — vide si rien trouvé, jamais `None`
- **`re.match()`** : différent de `search` — ne regarde qu'au **début** de la chaîne

| Fonction           | Cherche où       | Retourne                            |
| ------------------ | ---------------- | ----------------------------------- |
| `re.search(p, t)`  | N'importe où     | Premier Match ou `None`             |
| `re.findall(p, t)` | N'importe où     | Liste de toutes les correspondances |
| `re.match(p, t)`   | Début uniquement | Match ou `None`                     |
| `re.sub(p, r, t)`  | N'importe où     | Chaîne modifiée                     |

# 3️⃣ Le vocabulaire des regex

Une regex est composée de **caractères normaux** (qui se correspondent eux-mêmes) et de **métacaractères** (qui ont un sens spécial).

```python
import re

texte = "Réf: AB-2025-042, prix: 99.9 TND, email: client@shop.tn"

# ── \d : un chiffre [0-9] ─────────────────────────────────────────────────
print(re.findall(r"\d", texte))     # ['2', '0', '2', '5', '0', '4', '2', ...]
print(re.findall(r"\d+", texte))    # ['2025', '042', '99', '9']  ← + = un ou plus

# ── \w : lettre, chiffre ou _ ─────────────────────────────────────────────
print(re.findall(r"\w+", texte[:15]))   # ['Réf', 'AB', '2025', '042']

# ── \s : espace, tabulation, saut de ligne ────────────────────────────────
print(re.findall(r"\s", texte[:10]))    # [' ', ' ']

# ── . : N'IMPORTE quel caractère (sauf \n) ────────────────────────────────
print(re.findall(r"c.ient", texte))     # ['client']  — le . remplace 'l'
print(re.findall(r"9.9",    texte))     # ['99.9']    — le . remplace '.'

# ── [abc] : classe de caractères — UN parmi ceux listés ──────────────────
print(re.findall(r"[aeiou]", "bonjour"))   # ['o', 'o', 'u'] — voyelles seulement
print(re.findall(r"[A-Z]",   texte))       # ['R', 'A', 'B', 'T', 'N', 'D']
```

```
['2', '0', '2', '5', ...]
['2025', '042', '99', '9']
['Réf', 'AB', '2025', '042']
[' ', ' ']
['client']
['99.9']
['o', 'o', 'u']
['R', 'A', 'B', 'T', 'N', 'D']
```

**Tableau des métacaractères essentiels :**

| Métacaractère | Signification       | Exemple   | Correspond à       |
| ------------- | ------------------- | --------- | ------------------ |
| `\d`          | Un chiffre          | `\d+`     | `42`, `2025`       |
| `\D`          | Pas un chiffre      | `\D+`     | `abc`, `prix:`     |
| `\w`          | Lettre/chiffre/_    | `\w+`     | `CMD_001`          |
| `\s`          | Espace/tab/\n       | `\s+`     | , `\t`             |
| `.`           | N'importe quoi      | `c.t`     | `cat`, `cut`       |
| `[abc]`       | Un parmi a, b, c    | `[aeiou]` | `a`, `e`, `i`      |
| `[^abc]`      | Aucun parmi a, b, c | `[^0-9]`  | tout sauf chiffres |
| `[A-Z]`       | Plage de caractères | `[a-z]+`  | `bonjour`          |

- **majuscule = négation** : `\d` = chiffre, `\D` = pas un chiffre ; `\w` = mot, `\W` = pas un mot
- **`[^...]`** : le `^` à l'intérieur des crochets signifie "tout sauf" — différent du `^` ancre de début
- **`.` est piégeux** : il correspond même au `.` littéral — pour un point réel, écrire `\.`

# 4️⃣ Les quantificateurs — combien de fois ?

Les quantificateurs précisent **combien de fois** un motif doit se répéter.

```python
import re

# ── ? : 0 ou 1 fois (optionnel) ──────────────────────────────────────────
print(re.findall(r"colou?r", "color colour"))   # ['color', 'colour']
#                       ↑ 'u' est optionnel

# ── * : 0 ou plusieurs fois ───────────────────────────────────────────────
print(re.findall(r"ab*c", "ac abc abbc abbbc"))   # ['ac', 'abc', 'abbc', 'abbbc']

# ── + : 1 ou plusieurs fois ───────────────────────────────────────────────
print(re.findall(r"ab+c", "ac abc abbc"))   # ['abc', 'abbc']  — 'ac' exclu

# ── {n} : exactement n fois ───────────────────────────────────────────────
print(re.findall(r"\d{4}", "2025 25 12345"))    # ['2025', '1234']

# ── {n,m} : entre n et m fois ─────────────────────────────────────────────
print(re.findall(r"\d{2,4}", "5 25 250 2500 25000"))   # ['25', '250', '2500', '2500']

# ── Greedy vs Lazy : piège classique ──────────────────────────────────────
texte = "<b>gras</b> et <i>italique</i>"

greedy = re.findall(r"<.+>",  texte)   # gourmand : prend le maximum
lazy   = re.findall(r"<.+?>", texte)   # paresseux : prend le minimum

print("Greedy :", greedy)   # ['<b>gras</b> et <i>italique</i>']  ← tout !
print("Lazy   :", lazy)     # ['<b>', '</b>', '<i>', '</i>']       ← chaque balise
```

```
['color', 'colour']
['ac', 'abc', 'abbc', 'abbbc']
['abc', 'abbc']
['2025', '1234']
['25', '250', '2500', '2500']
Greedy : ['<b>gras</b> et <i>italique</i>']
Lazy   : ['<b>', '</b>', '<i>', '</i>']
```

| Quantificateur | Signification    | Exemple                          |
| -------------- | ---------------- | -------------------------------- |
| `?`            | 0 ou 1 fois      | `https?` → `http` ou `https`     |
| `*`            | 0 ou plusieurs   | `a*` → `""`, `a`, `aaa`          |
| `+`            | 1 ou plusieurs   | `\d+` → `1`, `42`, `2025`        |
| `{3}`          | Exactement 3     | `\d{3}` → `042`                  |
| `{2,5}`        | Entre 2 et 5     | `\w{2,5}` → `ab`, `abc`, `abcde` |
| `+?` ou `*?`   | Paresseux (lazy) | `<.+?>` → chaque balise          |

- **greedy par défaut** : `+`, `*`, `?` capturent le **maximum** possible — souvent ce qu'on veut
- **lazy avec `?`** : ajouter `?` après le quantificateur → capture le **minimum** — utile pour les balises HTML, guillemets
- **`{2,4}` sur `25000`** : trouve `2500` (4 chiffres max), puis `0` reste seul — `re.findall` ne superpose pas les correspondances

# 5️⃣ Anchors — où dans la chaîne ?

Les **anchors** (ancrages) ne correspondent pas à des caractères — ils indiquent une **position** dans la chaîne.

```python
import re

# ── ^ : début de chaîne ───────────────────────────────────────────────────
print(re.search(r"^\d+", "123 abc"))   # <Match '123'>  ✅
print(re.search(r"^\d+", "abc 123"))   # None           ❌ — 123 n'est pas au début

# ── $ : fin de chaîne ─────────────────────────────────────────────────────
print(re.search(r"\d+$", "abc 123"))   # <Match '123'>  ✅
print(re.search(r"\d+$", "123 abc"))   # None           ❌

# ── ^ et $ ensemble : validation complète ─────────────────────────────────
def valider_code_client(code):
    """Valide un code de type CLT-12345 (3 lettres, tiret, 5 chiffres)."""
    return bool(re.match(r"^[A-Z]{3}-\d{5}$", code))

print(valider_code_client("CLT-12345"))    # True  ✅
print(valider_code_client("CLT-1234"))     # False ❌ (4 chiffres)
print(valider_code_client("CLT-12345X"))   # False ❌ (caractère en trop)
print(valider_code_client("cl-12345"))     # False ❌ (minuscules)

# ── re.MULTILINE : ^ et $ par ligne ──────────────────────────────────────
logs = """INFO  Démarrage serveur
ERROR Connexion échouée
INFO  Requête reçue
ERROR Timeout"""

# Extraire toutes les lignes d'erreur
erreurs = re.findall(r"^ERROR.*", logs, re.MULTILINE)
print("Erreurs :", erreurs)
```

```
<re.Match object; span=(0, 3), match='123'>
None
<re.Match object; span=(4, 7), match='123'>
None
True
False
False
False
Erreurs : ['ERROR Connexion échouée', 'ERROR Timeout']
```

- **`^` et `$` sans `re.MULTILINE`** : ancrent au **début et fin de toute la chaîne**
- **`re.MULTILINE`** : `^` correspond au début de chaque **ligne**, `$` à la fin de chaque ligne
- **validation avec `^...$`** : garantit que **toute** la chaîne correspond — sans ça, `CLT-12345XYZ` serait accepté

# 6️⃣ Groupes de capture — extraire des parties

Les **parenthèses** créent des groupes qui capturent des parties du motif — on peut les récupérer individuellement.

```python
import re

texte = "Contacts : bechir@gmail.com, sarra@yahoo.fr, admin@boutique.tn"

# ── Sans groupe : findall retourne l'email entier ─────────────────────────
emails = re.findall(r"[\w.]+@[\w.]+\.[a-z]+", texte)
print("Emails :", emails)

# ── Avec groupes : findall retourne des tuples ────────────────────────────
pattern = r"([\w.]+)@([\w.]+)\.([a-z]+)"
#            ───────   ───────   ──────
#            groupe1   groupe2   groupe3

resultats = re.findall(pattern, texte)
print("\nDécomposés :")
for user, domaine, ext in resultats:
    print(f"  utilisateur={user:10}  domaine={domaine:10}  extension=.{ext}")

# ── Groupes nommés : encore plus lisible ─────────────────────────────────
pattern_nomme = r"(?P<user>[\w.]+)@(?P<domaine>[\w.]+)\.(?P<ext>[a-z]+)"

for match in re.finditer(pattern_nomme, texte):
    print(f"\n  {match.group('user')} chez {match.group('domaine')}.{match.group('ext')}")
```

```
Emails : ['bechir@gmail.com', 'sarra@yahoo.fr', 'admin@boutique.tn']

Décomposés :
  utilisateur=bechir      domaine=gmail       extension=.com
  utilisateur=sarra       domaine=yahoo       extension=.fr
  utilisateur=admin       domaine=boutique    extension=.tn

  bechir chez gmail.com
  sarra chez yahoo.fr
  admin chez boutique.tn
```

- **sans parenthèses** : `findall` retourne les chaînes complètes correspondant au motif
- **avec parenthèses** : `findall` retourne une **liste de tuples** — un tuple par correspondance, un élément par groupe
- **`(?P<nom>...)` groupe nommé** : accès par `match.group("nom")` — bien plus lisible que `match.group(1)`
- **`re.finditer()`** : comme `findall` mais retourne des **Match objects** — accès aux positions et aux groupes nommés

# 7️⃣ `finditer` — quand on a besoin de plus

`finditer` retourne un **itérateur de Match objects** au lieu d'une simple liste. Utile quand on a besoin des positions ou de groupes nommés.

```python
import re

log = """
[2025-03-12 08:42:01] ERROR 500 : Base de données inaccessible
[2025-03-12 09:15:33] INFO  200 : Requête traitée
[2025-03-12 09:58:47] ERROR 404 : Ressource introuvable
"""

pattern = r"\[(?P<date>\d{4}-\d{2}-\d{2}) (?P<heure>\d{2}:\d{2}:\d{2})\] (?P<niveau>\w+)\s+(?P<code>\d{3})"

print(f"{'Date':<12} {'Heure':<10} {'Niveau':<8} {'Code'}")
print("-" * 42)

for match in re.finditer(pattern, log):
    print(
        f"{match.group('date'):<12}",
        f"{match.group('heure'):<10}",
        f"{match.group('niveau'):<8}",
        f"{match.group('code')}"
    )
    # Bonus : position dans la chaîne
    # print(f"  Position : {match.start()} → {match.end()}")
```

```
Date         Heure      Niveau   Code
──────────────────────────────────────────
2025-03-12   08:42:01   ERROR    500
2025-03-12   09:15:33   INFO     200
2025-03-12   09:58:47   ERROR    404
```

- **`match.start()` / `match.end()`** : position de début et fin de la correspondance dans la chaîne — utile pour l'annotation de texte
- **`match.group("date")`** : accès par nom — beaucoup plus clair que `match.group(1)` sur une regex complexe
- **`finditer` vs `findall`** : `finditer` est **paresseux** (lazy) — n'analyse que ce qu'on demande, meilleur pour les gros fichiers

# 8️⃣ Lookahead et Lookbehind — capturer sans inclure

Les **assertions** permettent de conditionner une correspondance à ce qui la précède ou la suit — **sans capturer** ce contexte.

```python
import re

# ── Lookahead (?=...) : "suivi de" ───────────────────────────────────────
prix = "Produit: 99 TND, Taxe: 15 TND, Total: 114 TND"

# Capturer les nombres SUIVIS de " TND" — sans inclure " TND"
montants = re.findall(r"\d+(?= TND)", prix)
print("Montants :", montants)   # ['99', '15', '114']

# ── Lookbehind (?<=...) : "précédé de" ───────────────────────────────────
references = "REF:A001 REF:B002 CODE:C003"

# Capturer ce qui vient APRÈS "REF:" — sans inclure "REF:"
refs = re.findall(r"(?<=REF:)\w+", references)
print("Références :", refs)   # ['A001', 'B002']  — C003 ignoré (précédé de CODE:)

# ── Lookahead négatif (?!...) : "pas suivi de" ───────────────────────────
versions = "v1.0 v2.0-beta v3.0 v4.0-alpha"

# Capturer les versions NON suivies de "-"
stables = re.findall(r"v\d+\.\d+(?!-)", versions)
print("Versions stables :", stables)   # ['v1.0', 'v3.0']
```

```
Montants : ['99', '15', '114']
Références : ['A001', 'B002']
Versions stables : ['v1.0', 'v3.0']
```

```
Syntaxe des assertions :

  (?=abc)   lookahead positif    : suivi de "abc"
  (?!abc)   lookahead négatif    : pas suivi de "abc"
  (?<=abc)  lookbehind positif   : précédé de "abc"
  (?<!abc)  lookbehind négatif   : pas précédé de "abc"

  Dans tous les cas : la condition est vérifiée mais PAS capturée
```

- **`\d+(?= TND)`** : trouve les chiffres — mais seulement ceux **suivis** de `TND` — le `TND` n'est pas dans le résultat
- **`(?<=REF:)\w+`** : trouve les mots — mais seulement ceux **précédés** de `REF:` — le `REF:` n'est pas dans le résultat
- **use case typique** : extraire une valeur sans son libellé (`prix:`, `=`, `:`), filtrer selon le contexte

# 9️⃣ Compilation et flags — performances et options

Quand une regex est utilisée **plusieurs fois**, la compiler avec `re.compile()` évite de la reparser à chaque fois.

```python
import re

# ── re.compile() : compiler une regex pour réutilisation ─────────────────
# Sans compilation : Python reparse le pattern à chaque appel
# Avec compilation : pattern analysé une seule fois, réutilisé

email_regex = re.compile(
    r"(?P<user>[\w.]+)@(?P<domaine>[\w]+)\.(?P<ext>[a-z]{2,4})",
    re.IGNORECASE   # flag : insensible à la casse
)

# Réutilisation sur plusieurs textes
textes = [
    "Contact : Bechir@Gmail.COM",
    "Support : ADMIN@boutique.tn",
    "pas un email",
]

for t in textes:
    m = email_regex.search(t)
    if m:
        print(f"  ✅ {m.group('user')} @ {m.group('domaine')}.{m.group('ext')}")
    else:
        print(f"  ❌ Aucun email dans : '{t}'")

# ── Les flags les plus utiles ─────────────────────────────────────────────
texte_multilignes = "Python\nJava\nPython"

# re.IGNORECASE : insensible à la casse
print(re.findall(r"python", texte_multilignes, re.IGNORECASE))   # ['Python', 'Python']

# re.MULTILINE : ^ et $ par ligne
print(re.findall(r"^Python", texte_multilignes, re.MULTILINE))   # ['Python', 'Python']

# re.DOTALL : le . correspond aussi aux \n
print(re.findall(r"Python.Java", texte_multilignes, re.DOTALL))  # ['Python\nJava']
```

```
  ✅ Bechir @ Gmail.COM
  ✅ ADMIN @ boutique.tn
  ❌ Aucun email dans : 'pas un email'
['Python', 'Python']
['Python', 'Python']
['Python\nJava']
```

| Flag            | Abréviation | Effet                             |
| --------------- | ----------- | --------------------------------- |
| `re.IGNORECASE` | `re.I`      | Insensible à la casse             |
| `re.MULTILINE`  | `re.M`      | `^`/`$` par ligne                 |
| `re.DOTALL`     | `re.S`      | `.` correspond aussi à `\n`       |
| `re.VERBOSE`    | `re.X`      | Permet commentaires dans la regex |

- **`re.compile(pattern, flags)`** : pré-compile la regex — bénéfique dans les boucles sur gros volumes
- **plusieurs flags** : les combiner avec `|` → `re.IGNORECASE | re.MULTILINE`
- **`re.VERBOSE`** : permet d'écrire une regex sur plusieurs lignes avec des commentaires — idéal pour les patterns complexes

# 🔟 `re.sub` — nettoyer et transformer des données

`re.sub` est l'outil de **nettoyage de données** par excellence — remplace toutes les occurrences d'un motif.

```python
import re

# ── Nettoyage de base ─────────────────────────────────────────────────────
texte_brut = "  Bonjour   Bechir  ,   comment   vas-tu  ?  "

# Normaliser les espaces multiples
propre = re.sub(r"\s+", " ", texte_brut).strip()
print(propre)   # Bonjour Bechir , comment vas-tu ?

# ── Anonymisation ─────────────────────────────────────────────────────────
log = "User bechir@gmail.com a payé 149.90 TND avec carte 4532-1234-5678-9010"

# Masquer les emails
log = re.sub(r"[\w.]+@[\w.]+\.[a-z]+", "***@***.***", log)

# Masquer les numéros de carte bancaire
log = re.sub(r"\d{4}-\d{4}-\d{4}-\d{4}", "****-****-****-****", log)

print(log)

# ── Transformation avec fonction ─────────────────────────────────────────
# re.sub accepte une FONCTION comme remplacement
prix_texte = "article1: 99 EUR, article2: 149 EUR, article3: 25 EUR"

def eur_vers_tnd(match):
    """Convertit EUR en TND (×3.38)."""
    montant = int(match.group(1))
    return f"{montant * 3.38:.0f} TND"

resultat = re.sub(r"(\d+) EUR", eur_vers_tnd, prix_texte)
print(resultat)
```

```
Bonjour Bechir , comment vas-tu ?
User ***@***.*** a payé 149.90 TND avec carte ****-****-****-****
article1: 335 TND, article2: 504 TND, article3: 85 TND
```

- **`re.sub(pattern, remplacement, texte)`** : remplace **toutes** les occurrences — retourne une nouvelle chaîne (les chaînes Python sont immuables)
- **`re.sub(pattern, fonction, texte)`** : la fonction reçoit chaque Match object et retourne le texte de remplacement — permet des transformations calculées
- **`match.group(1)`** dans la fonction de remplacement : accède aux groupes capturés — indispensable pour transformer la valeur trouvée

# 1️⃣1️⃣ Groupes nommés — regex lisibles et maintenables

Sur une regex complexe, `match.group(1)` devient illisible. Les **groupes nommés** rendent le code autodocumenté.

```python
import re

# ── Extraction structurée d'un log applicatif ─────────────────────────────
log_pattern = re.compile(
    r"\[(?P<date>\d{4}-\d{2}-\d{2})\]"   # [2025-03-12]
    r"\s\[(?P<niveau>INFO|ERROR|WARN)\]"   # [ERROR]
    r"\s(?P<code>\d{3})"                   # 404
    r"\s(?P<message>.+)"                   # message libre
)

logs = [
    "[2025-03-12] [ERROR] 500 Base de données inaccessible",
    "[2025-03-12] [INFO]  200 Requête traitée avec succès",
    "[2025-03-13] [WARN]  301 Redirection permanente",
]

erreurs = []

for ligne in logs:
    m = log_pattern.match(ligne)
    if m:
        entree = m.groupdict()   # retourne un dict {nom: valeur}
        print(f"  [{entree['niveau']}] {entree['date']} — code {entree['code']}")
        if entree["niveau"] == "ERROR":
            erreurs.append(entree)

print(f"\n{len(erreurs)} erreur(s) détectée(s) :")
for e in erreurs:
    print(f"  ⚠️  {e['message']}")
```

- **`(?P<nom>...)`** : groupe nommé — accès par `match.group("nom")` ou via le dict `match.groupdict()`
- **`m.groupdict()`** : retourne **tous** les groupes nommés dans un dictionnaire — pratique pour passer les données à une fonction ou une dataclass
- **concaténation de raw strings** : `r"..." r"..."` — Python les joint automatiquement — permet de décomposer une regex longue en plusieurs lignes lisibles

# 1️⃣2️⃣ Bonnes pratiques

```python
import re

# ✅ Pratique 1 : toujours utiliser des raw strings
pattern_bon    = r"\d+\.\d+"   # ← correct : \d est un métacaractère regex
pattern_mauvais = "\d+\.\d+"   # ← risqué  : \d peut être interprété par Python

# ✅ Pratique 2 : compiler si usage répété
email_re = re.compile(r"[\w.]+@[\w.]+\.[a-z]+")   # compilé une fois
textes = ["a@b.com", "c@d.fr", "pas_un_email"]
for t in textes:
    print(email_re.search(t))   # réutilisé sans reparser

# ✅ Pratique 3 : toujours vérifier si match est None avant .group()
m = re.search(r"\d+", "abc")
if m:                            # ← toujours cette vérification
    print(m.group())
# Sans vérification → AttributeError: 'NoneType' object has no attribute 'group'

# ✅ Pratique 4 : nommer les groupes sur les patterns complexes
# ❌ illisible
m = re.search(r"(\d+)-(\d+)-(\d+)", "2025-03-12")
print(m.group(1), m.group(2), m.group(3))

# ✅ clair
m = re.search(r"(?P<annee>\d+)-(?P<mois>\d+)-(?P<jour>\d+)", "2025-03-12")
print(m.group("annee"), m.group("mois"), m.group("jour"))

# ✅ Pratique 5 : ne pas parser du HTML/XML avec regex
# → utiliser BeautifulSoup ou lxml à la place
```

**Guide de choix des fonctions `re` :**

```
Je veux...
│
├── Vérifier si un motif EXISTE ?
│       → re.search(p, t)     if re.search(p, t): ...
│
├── Vérifier que toute la chaîne correspond ?
│       → re.match(r"^...$", t)  ou  re.fullmatch(p, t)
│
├── Récupérer TOUTES les correspondances (liste) ?
│       → re.findall(p, t)
│
├── Récupérer toutes les correspondances + positions ?
│       → re.finditer(p, t)     for m in re.finditer(...):
│
├── REMPLACER des occurrences ?
│       → re.sub(p, remplacement, t)
│
└── Utiliser la même regex plusieurs fois ?
        → re.compile(p)  puis  regex.findall(t), regex.search(t)...
```

> ✅ **Récapitulatif — les 6 points clés**
> 
> **`r"..."`** toujours pour les patterns · **`\d \w \s .`** sont les métacaractères de base · **`+?*{n}`** contrôlent les répétitions · **`(...)` groupes** pour capturer des parties · **`^$`** ancrent la position · **`re.compile()`** quand on réutilise le même pattern

# 20) Comment construire un analyseur simple complet ?

## Énoncé

Lire un texte, extraire emails, compter domaines.

## Solution

```python
"""
Explication :
Script complet combinant lecture, compilation,
extraction, structuration et affichage.
"""

import re
from collections import Counter

with open("emails.txt", "r", encoding="utf-8") as file:
    content = file.read()

pattern = re.compile(r"([A-Za-z]+)@([A-Za-z]+)\.(fr|com|ch)", re.IGNORECASE)

domaines = []

for match in pattern.finditer(content):
    utilisateur = match.group(1)
    domaine = match.group(2)
    extension = match.group(3)

    print("Utilisateur :", utilisateur)
    print("Domaine :", domaine)
    print("Extension :", extension)
    print("-" * 20)

    domaines.append(domaine)

statistiques = Counter(domaines)

print("Résumé statistique :", statistiques)
```
