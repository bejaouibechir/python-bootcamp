Milestone 9 — Rapport stock Excel coloré & import bon de commande¶

Le support est une propriété de Bechir Bejaoui

Objectif du sprint¶

Connecter Al Qalam Stock Manager au monde professionnel Excel via openpyxl.
À la fin de ce sprint, l'application peut :

  • Générer un classeur Excel .xlsx multi-feuilles avec colorisation conditionnelle du stock
  • Styliser les cellules : polices, alignements, bordures, largeurs de colonnes adaptées
  • Fusionner des cellules pour les titres et les lignes de totaux
  • Insérer un graphique en barres dans la feuille Statistiques
  • Lire un bon de commande fournisseur Excel et approvisionner le stock automatiquement
  • Prévisualiser un fichier Excel avant de l'importer (structure + aperçu des données)

Concepts Python mis en pratique¶

Concept Classe / Fonction Usage dans Al Qalam
Workbook / Worksheet openpyxl Création classeur multi-feuilles
PatternFill openpyxl.styles Colorisation conditionnelle (rouge/orange/vert)
Font / Alignment / Border openpyxl.styles Mise en forme professionnelle

EXCEL_DIR             = DATA_DIR / "excel"   # dossier exports Excel

2. services/excel_service.py — ExcelService¶

Export : rapport de stock multi-feuilles¶

service = ExcelService(stock_service)
chemin  = service.exporter_rapport_stock()   # → Path du .xlsx créé

Feuille 1 — "📦 Catalogue"
- Toutes les colonnes produit : ref, nom, catégorie, qté, seuil, prix, valeur, marge, statut
- Colorisation conditionnelle ligne par ligne selon l'état du stock
- Ligne de total fusionnée (7 colonnes) avec valeur totale du stock
- En-têtes figés avec freeze_panes

Feuille 2 — "⚠️ Ruptures"
- Filtre automatique sur les produits avec qte ≤ seuil_min
- Message "Aucune rupture" si le stock est en parfait état

Feuille 3 — "📊 Statistiques"
- Agrégation par catégorie : nb produits, valeur stock, marge totale, ruptures, alertes
- Ligne TOTAL GÉNÉRAL
- Graphique en barres verticales (valeur de stock par catégorie)

Import : bon de commande fournisseur¶

rapport = service.importer_bon_commande("bon_commande.xlsx")
# → {"traites": 5, "erreurs": [], "total_lues": 6, "total_qte": 90}
  • Lit la première feuille du classeur
  • Ligne 1 : en-têtes (doit contenir ref et qte, note optionnel)
  • Pour chaque ligne valide : appelle stock_service.entree_stock(ref, qte, note)
  • Lignes invalides (ref inconnue, qté négative) → rapport d'erreurs sans interruption

Prévisualisation¶

apercu = service.previsualiser_excel("fichier.xlsx", nb_lignes=5)
# → {"colonnes": [...], "lignes": [...], "valide": True, "feuilles": [...]}

Points clés openpyxl à retenir¶

Colorisation conditionnelle (côté Python, pas formule Excel)¶

# On choisit la couleur AVANT d'écrire la cellule, selon la logique métier
if produit.qte == 0:
    couleur = EXCEL_COULEUR_RUPTURE   # rouge pâle
elif produit.qte <= produit.seuil_min:
    couleur = EXCEL_COULEUR_ALERTE    # orange pâle
else:
    couleur = EXCEL_COULEUR_OK        # vert pâle

cellule.fill = PatternFill(fill_type="solid", fgColor=couleur)

Graphique en barres¶

from openpyxl.chart import BarChart, Reference

chart = BarChart()
chart.type  = "col"            # barres verticales
chart.title = "Valeur par catégorie"

# Données : colonne C, lignes 2 → 2+nb_cats (inclut en-tête pour légende)
data = Reference(ws, min_col=3, max_col=3, min_row=2, max_row=2 + nb_cats)
cats = Reference(ws, min_col=1, min_row=3, max_row=2 + nb_cats)

chart.add_data(data, titles_from_data=True)
chart.set_categories(cats)
ws.add_chart(chart, "A10")   # position dans la feuille

Lecture d'un Excel externe¶

wb = openpyxl.load_workbook("fichier.xlsx", data_only=True)
ws = wb.active

entetes = [str(c.value).strip().lower() for c in ws[1]]

for ligne in ws.iter_rows(min_row=2, values_only=True):
    if all(v is None for v in ligne):
        continue          # ignorer lignes vides
    ref = ligne[entetes.index("ref")]
    qte = int(float(str(ligne[entetes.index("qte")])))
