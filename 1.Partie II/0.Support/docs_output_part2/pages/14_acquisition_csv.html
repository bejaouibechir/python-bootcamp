🚀 Préparation¶

Avant de commencer, générer tous les fichiers CSV de l'atelier en une seule commande :

# Placer generate_csv.py dans votre dossier de travail, puis :
python generate_csv.py

# Les fichiers sont créés dans C:\temp\io\

python generate_csv.py D:\data\io

Tous les fichiers cas01_header.csv → cas08_pandas.csv et q01 → q15 sont créés automatiquement. Pas besoin de les créer à la main.

1️⃣ Pourquoi lire des CSV avec Python ?¶

Un CSV (Comma-Separated Values) est le format d'échange de données le plus répandu. Exports bancaires, logs, catalogues produits, données RH — tout passe par CSV. Python propose deux approches : le module csv (standard, léger) et pandas (puissant, analytique).

Fichier CSV brut :                Python le lit comme :

policyID,statecode,county         ligne 0 (header) : ['policyID', 'statecode', 'county']
119736,FL,CLAY COUNTY      →      ligne 1 (data)   : ['119736', 'FL', 'CLAY COUNTY']
448094,FL,CLAY COUNTY             ligne 2 (data)   : ['448094', 'FL', 'CLAY COUNTY']

                                  ⚠️ TOUT est une chaîne de caractères par défaut
                                  119736 est lu comme "119736", pas comme l'entier 119736
  • csv.reader : lit ligne par ligne — chaque ligne est une liste de chaînes — accès par index (ligne[0])
  • csv.DictReader : lit ligne par ligne — chaque ligne est un dictionnaire — accès par nom de colonne (ligne["policyID"])
  • pandas : charge tout en mémoire dans un DataFrame — idéal pour l'analyse, les filtres, les agrégations
  • règle de base : tout CSV lu est en mode texte — toujours convertir explicitement les nombres (int(), float())

2️⃣ Cas 1 — Lecture brute avec csv.reader¶

Fichier utilisé : cas01_header.csv

policyID,statecode,county
119736,FL,CLAY COUNTY
448094,FL,CLAY COUNTY
206893,FL,CLAY COUNTY

import csv

fichier = r"C:\temp\io\cas01_header.csv"

with open(fichier, mode="r", encoding="utf-8") as f:
    lecteur = csv.reader(f, delimiter=",")

    for index, ligne in enumerate(lecteur):

        if index == 0:
            # La première ligne est l'en-tête
            print("Colonnes :", ligne)
            continue

        # Accès par position dans la liste
        policy_id = ligne[0]
        state     = ligne[1]
        county    = ligne[2]

        print(f"  {policy_id} | {state} | {county}")

Colonnes : ['policyID', 'statecode', 'county']
  119736 | FL | CLAY COUNTY
  448094 | FL | CLAY COUNTY
  206893 | FL | CLAY COUNTY
  • open(..., encoding="utf-8") : toujours préciser l'encodage — sans ça, Python utilise l'encodage système (peut échouer sur Windows avec les accents)
  • csv.reader : retourne un itérateur — chaque ligne est une liste de chaînes
  • enumerate(lecteur) : donne l'index de chaque ligne — pratique pour détecter la ligne 0 (l'en-tête)
  • if index == 0: continue : on affiche l'en-tête séparément puis on passe à la suite
  • accès par index (ligne[0]) : fragile — si l'ordre des colonnes change dans le fichier, le code casse

Fichier utilisé : cas02_dict.csv

policyID,statecode,county

import csv

    # DictReader détecte automatiquement l'en-tête

Colonnes disponibles : ['policyID', 'statecode', 'county']
  ID: 333743   | Comté: CLAY COUNTY
  ID: 172534   | Comté: SUWANNEE COUNTY
  ID: 995932   | Comté: PINELLAS COUNTY

csv.reader vs csv.DictReader :

csv.reader csv.DictReader
Accès aux données ligne[0], ligne[1] ligne["policyID"]
Gestion du header Manuelle (index == 0) Automatique
Robustesse Fragile si ordre change ✅ Stable
Lisibilité Moins claire ✅ Claire
Performance Légèrement plus rapide Négligeable
  • lecteur.fieldnames : liste des noms de colonnes, disponible après la première lecture — utile pour valider la structure avant de traiter les données
  • DictReader est recommandé dans 95% des cas — le code est plus lisible et résistant aux changements de schéma

4️⃣ Cas 3 — Délimiteur ; et nettoyage des espaces¶

Tous les CSV n'utilisent pas la virgule comme séparateur. Les exports européens utilisent souvent ; (la virgule étant réservée aux décimales).

Fichier utilisé : cas03_delim.csv

policyID; statecode; county
119736; FL; CLAY COUNTY
448094; FL; CLAY COUNTY
206893; FL; CLAY COUNTY

import csv

fichier = r"C:\temp\io\cas03_delim.csv"

with open(fichier, mode="r", encoding="utf-8") as f:
    lecteur = csv.reader(f, delimiter=";")

    for index, ligne in enumerate(lecteur):

        # Nettoyer les espaces autour de chaque champ
        champs = [c.strip() for c in ligne]

        if index == 0:
            print("Header nettoyé :", champs)
            continue

        print(f"  {champs[0]} | {champs[1]} | {champs[2]}")

Header nettoyé : ['policyID', 'statecode', 'county']
  119736 | FL | CLAY COUNTY
  448094 | FL | CLAY COUNTY
  206893 | FL | CLAY COUNTY

Sans .strip() :

# Le champ "statecode" lu brut serait " statecode" (avec espace devant)
# La comparaison ligne["statecode"] == "FL" échouerait silencieusement !
champ_brut = " FL"
print(champ_brut == "FL")          # False  ← bug difficile à détecter
print(champ_brut.strip() == "FL")  # True   ✅
  • delimiter=";" : indique à csv.reader le caractère séparateur — par défaut c'est ",", ici on le change
  • [c.strip() for c in ligne] : applique .strip() sur chaque champ de la ligne pour enlever espaces en début et fin
  • piège courant : un espace invisible dans " FL" ne se voit pas à l'œil nu mais casse toutes les comparaisons

5️⃣ Cas 4 — Conversion de types et gestion des erreurs¶

Le contenu d'un CSV est toujours du texte. Pour faire des calculs, il faut convertir. Mais les données réelles sont souvent sales (valeurs manquantes, texte là où on attend un nombre).

Fichier utilisé : cas04_types.csv

policyID,tiv_2011,tiv_2012
119736,498960,792148.9
448094,1322376.3,1438163.57
206893,ABC,192476.78        ← valeur invalide
333743,79520.76,            ← valeur manquante

import csv

fichier = r"C:\temp\io\cas04_types.csv"

valides   = 0
invalides = 0

with open(fichier, mode="r", encoding="utf-8") as f:
    lecteur = csv.DictReader(f)

    for ligne in lecteur:
        try:
            policy_id = int(ligne["policyID"])
            tiv_2011  = float(ligne["tiv_2011"])
            tiv_2012  = float(ligne["tiv_2012"])

            variation = tiv_2012 - tiv_2011
            print(f"  ✅ #{policy_id} | variation : {variation:+.2f}")
            valides += 1

        except ValueError as e:
            # float("ABC") → ValueError
            # float("")    → ValueError (champ vide)
            print(f"  ❌ Ligne rejetée : {dict(ligne)} — {e}")
            invalides += 1

print(f"\nRésumé : {valides} valides | {invalides} invalides")

  ✅ #119736 | variation : +293188.90
  ✅ #448094 | variation : +115787.27
  ❌ Ligne rejetée : {'policyID': '206893', 'tiv_2011': 'ABC', ...} — could not convert...
  ❌ Ligne rejetée : {'policyID': '333743', 'tiv_2011': '79520.76', 'tiv_2012': ''} — ...

Résumé : 2 valides | 2 invalides
  • int(ligne["policyID"]) : convertit la chaîne "119736" en entier Python — lève ValueError si impossible
  • float("") : un champ vide dans le CSV donne la chaîne vide "" — float("") lève ValueError
  • try/except ValueError : la bonne pratique — on ne laisse pas une ligne corrompue planter tout le programme
  • dict(ligne) dans le message d'erreur : affiche la ligne complète pour faciliter le débogage

6️⃣ Cas 5 — Validation de structure avant traitement¶

Avant de traiter des milliers de lignes, vérifier que le fichier a bien toutes les colonnes attendues. Mieux vaut échouer vite avec un message clair que planter au milieu du traitement.

Fichier utilisé : cas05_invalide.csv

policyID,statecode
119736,FL
448094,FL

(les colonnes tiv_2011 et tiv_2012 sont absentes)

import csv

COLONNES_REQUISES = {"policyID", "tiv_2011", "tiv_2012"}
fichier = r"C:\temp\io\cas05_invalide.csv"

with open(fichier, mode="r", encoding="utf-8") as f:
    lecteur = csv.DictReader(f)

    colonnes_presentes = set(lecteur.fieldnames or [])
    manquantes = COLONNES_REQUISES - colonnes_presentes

    if manquantes:
        raise ValueError(
            f"Fichier invalide — colonnes manquantes : {', '.join(sorted(manquantes))}"
        )

    # Ce code n'est atteint que si la structure est correcte
    print("✅ Structure validée — traitement en cours...")
    for ligne in lecteur:
        pass

ValueError: Fichier invalide — colonnes manquantes : tiv_2011, tiv_2012
  • lecteur.fieldnames : liste des colonnes lues dans l'en-tête — disponible avant d'itérer sur les lignes
  • set(colonnes_requises) - set(colonnes_presentes) : différence d'ensembles — retourne les colonnes manquantes
  • raise ValueError au lieu d'une Exception générique : le type d'erreur informe sur la nature du problème
  • valider en premier : si la structure est invalide, on échoue à la ligne 10 avec un message clair plutôt qu'à la ligne 50 000 avec un KeyError

7️⃣ Cas 6 — Règle métier : détecter les variations > 20%¶

On applique maintenant une logique métier sur les données : identifier les contrats dont la valeur assurée a augmenté de plus de 20% entre 2011 et 2012.

Fichier utilisé : cas06_variation.csv

policyID,tiv_2011,tiv_2012
119736,498960,792148.9
448094,1322376.3,1438163.57
206893,190724.4,192476.78
333743,79520.76,86854.48
172534,254281.5,246144.49

import csv

fichier = r"C:\temp\io\cas06_variation.csv"
SEUIL   = 0.20   # 20%

alertes = []

with open(fichier, mode="r", encoding="utf-8") as f:
    lecteur = csv.DictReader(f)

    for ligne in lecteur:
        try:
            tiv_2011 = float(ligne["tiv_2011"])
            tiv_2012 = float(ligne["tiv_2012"])

            if tiv_2011 <= 0:
                continue   # éviter division par zéro

            variation = (tiv_2012 - tiv_2011) / tiv_2011

            if variation > SEUIL:
                alertes.append({
                    "id"       : ligne["policyID"],
                    "variation": variation,
                    "delta"    : tiv_2012 - tiv_2011
                })

        except ValueError:
            continue   # ignorer les lignes non numériques

print(f"{'ID':<10} {'Variation':>10} {'Delta':>15}")
print("-" * 38)
for a in alertes:
    print(f"{a['id']:<10} {a['variation']*100:>9.1f}% {a['delta']:>14.2f}")

print(f"\n{len(alertes)} contrat(s) en alerte (hausse > {SEUIL*100:.0f}%)")

ID         Variation           Delta
──────────────────────────────────────
119736        58.8%      293188.90
333743         9.2%        7333.72   ← sous le seuil, pas affiché
...

1 contrat(s) en alerte (hausse > 20%)
  • variation = (tiv_2012 - tiv_2011) / tiv_2011 : formule de variation relative — toujours vérifier tiv_2011 > 0 avant
  • SEUIL = 0.20 : constante en haut du script — facile à modifier sans chercher dans le code
  • collecter dans une liste alertes : séparer la lecture/calcul de l'affichage — code plus propre et testable
  • continue dans le except : on ignore silencieusement les lignes non exploitables — dans un vrai projet, on les loguerait

8️⃣ Cas 7 — Export filtré vers un nouveau CSV¶

Lire un CSV, filtrer les lignes selon un critère, écrire le résultat dans un nouveau fichier CSV — c'est un pipeline ETL minimal.

Fichier source : cas07_export_source.csv

policyID,county,tiv_2012
119736,CLAY COUNTY,792148.9
448094,CLAY COUNTY,1438163.57
206893,CLAY COUNTY,192476.78
333743,CLAY COUNTY,86854.48
142071,PINELLAS COUNTY,1200000

Fichier produit : cas07_export_resultat.csv (lignes avec tiv_2012 > 1 000 000)

import csv

source = r"C:\temp\io\cas07_export_source.csv"
cible  = r"C:\temp\io\cas07_export_resultat.csv"
SEUIL  = 1_000_000

nb_lues  = 0
nb_ecrites = 0

with open(source, mode="r", encoding="utf-8") as f_in, \
     open(cible,  mode="w", newline="", encoding="utf-8") as f_out:

    lecteur = csv.DictReader(f_in)

    # Conserver exactement les mêmes colonnes que la source
    writer = csv.DictWriter(f_out, fieldnames=lecteur.fieldnames)
    writer.writeheader()

    for ligne in lecteur:
        nb_lues += 1
        try:
            if float(ligne["tiv_2012"]) > SEUIL:
                writer.writerow(ligne)
                nb_ecrites += 1
        except ValueError:
            continue   # ignorer les valeurs non numériques

print(f"✅ Terminé : {nb_lues} lignes lues | {nb_ecrites} lignes exportées")
print(f"   Fichier produit : {cible}")

✅ Terminé : 5 lignes lues | 2 lignes exportées
   Fichier produit : C:\temp\io\cas07_export_resultat.csv

Contenu de cas07_export_resultat.csv :

policyID,county,tiv_2012
448094,CLAY COUNTY,1438163.57
142071,PINELLAS COUNTY,1200000
  • open(source, "r") ET open(cible, "w") dans le même with : les deux fichiers sont ouverts simultanément — Python ferme les deux proprement à la sortie
  • newline="" obligatoire sur le fichier d'écriture : sans ça, Python ajoute \r\r\n sous Windows — les lignes sont doublées
  • fieldnames=lecteur.fieldnames : le writer utilise exactement les mêmes colonnes que le reader — pas besoin de les lister à la main
  • writer.writeheader() : écrit la ligne d'en-tête — à ne pas oublier sinon le fichier résultat n'a pas de header

🔟 csv vs Pandas — guide de choix¶

import csv
import pandas as pd

# ── Quand utiliser csv (module standard) ──────────────────────────────────
# ✅ Traitement ligne par ligne sans tout charger en mémoire
# ✅ Fichiers très volumineux (> 1 Go)
# ✅ Transformations simples et exports
# ✅ Pas de dépendance externe (pandas doit être installé)

with open(r"C:\temp\io\cas06_variation.csv", "r", encoding="utf-8") as f:
    lecteur = csv.DictReader(f)
    for ligne in lecteur:
        pass   # traitement ligne par ligne — mémoire constante

# ── Quand utiliser pandas ─────────────────────────────────────────────────
# ✅ Analyse statistique (mean, std, describe)
# ✅ Filtres et tris complexes
# ✅ Agrégations par groupe (groupby)
# ✅ Jointures entre plusieurs fichiers (merge)
# ✅ Visualisation des données

df = pd.read_csv(r"C:\temp\io\cas08_pandas.csv")

# En 3 lignes : filtrer + trier + agréger
resultat = (df[df["tiv_2012"] > 500_000]
              .sort_values("tiv_2012", ascending=False)
              .groupby("county")["tiv_2012"]
              .sum())
print(resultat)

1 — Pourquoi newline="" est-il important à l’écriture ?¶

Énoncé¶

Pourquoi faut-il utiliser newline="" dans open lors d’un export CSV sous Windows ?

Créer le fichier
C:\temp\io\q01_source.csv

id,nom
1,Alice
2,Bob

Créer le fichier
C:\temp\io\q01_newline.py

"""
Problème :
Sous Windows, sans newline="",
les lignes écrites peuvent contenir des lignes vides supplémentaires.

Démonstration :
Écrire un CSV avec et sans newline.
Observer le résultat.
"""

import csv

source = r"C:\temp\io\q01_source.csv"
mauvais = r"C:\temp\io\q01_mauvais.csv"
bon = r"C:\temp\io\q01_bon.csv"

# Mauvaise écriture (peut créer des lignes vides)
with open(mauvais, "w", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerow(["id", "nom"])
    writer.writerow([1, "Alice"])
    writer.writerow([2, "Bob"])

# Bonne écriture
with open(bon, "w", newline="", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerow(["id", "nom"])
    writer.writerow([1, "Alice"])

"""

import csv

source = r"C:\temp\io\q15_source.csv"
cible = r"C:\temp\io\q15_result.csv"

with open(source, "r", encoding="utf-8") as f_in, \
     open(cible, "w", newline="", encoding="utf-8") as f_out:

    lecteur = csv.DictReader(f_in)

    writer = csv.DictWriter(f_out, fieldnames=["id", "nom"])

            "id": ligne["id"],
            "nom": ligne["nom"]
        })
