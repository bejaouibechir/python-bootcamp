📚 Python Avancé — Partie 2 : POO, Fichiers & Tests

Bienvenue dans la documentation

Cette documentation couvre la Partie 2 du cours Python Avancé, organisée en 11 chapitres théoriques et 11 milestones pratiques appliqués au projet Al Qalam Stock Manager (papeterie tunisienne).

Thèmes abordés

  • 🏛️ Programmation Orientée Objet (POO) — classes, héritage, méthodes magiques
  • ⚡ Compréhensions, décorateurs, descripteurs, métaclasses
  • 🧵 Threading, coroutines, programmation concurrente
  • 📂 Acquisition de données — Regex, CSV, Excel, Bases de données
  • 🧪 Tests Python — pytest, couverture, fixtures
