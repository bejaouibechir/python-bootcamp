# 1️⃣ Comprendre la hiérarchie réelle

En Python :

- Une instance est créée à partir d’une classe

- Une classe est créée à partir d’une méta-classe

- La méta-classe par défaut est type

Schéma conceptuel :

Objet → Classe → Méta-classe → type

---

# 2️⃣ Rappel fondamental : tout est objet

```python
"""
Démonstration
Une classe est elle-même une instance de type.
"""

class A:
    pass

print("Type de A :", type(A))
print("Type de instance :", type(A()))
```

Sortie attendue :

Type de A : <class 'type'>  
Type de instance : <class '**main**.A'>

Conclusion :

- A est instance de type

- type est la méta-classe par défaut

# 4️⃣ Anatomie d’une méta-classe personnalisée

Une méta-classe est une classe qui hérite de type.

Elle intercepte :

- la création de classe → **new**

- l’initialisation de classe → **init**

- l’instanciation → **call**

---

# 5️⃣ Méta-classe minimaliste

```python
"""
Cette méta-classe trace la création de toute classe qui l’utilise.
"""

class TraceMeta(type):

    def __new__(cls, name, bases, namespace):
        print(f"[Meta __new__] Création de la classe {name}")
        return super().__new__(cls, name, bases, namespace)

    def __init__(cls, name, bases, namespace):
        print(f"[Meta __init__] Initialisation de la classe {name}")
        super().__init__(name, bases, namespace)

    def __call__(cls, *args, **kwargs):
        print(f"[Meta __call__] Instanciation de {cls.__name__}")
        return super().__call__(*args, **kwargs)
```

Contexte :

Nous développons un mini ORM interne.

```python
"""
Méta-classe qui impose une convention métier.
"""

class ModelMeta(type):

    def __new__(cls, name, bases, namespace):
        if name != "BaseModel":
            if "__tablename__" not in namespace:
                raise TypeError(
                    f"La classe {name} doit définir __tablename__"

        return super().__new__(cls, name, bases, namespace)
```

Explication
- __call__ de la méta-classe contrôle l’instanciation.

## 14) Peut-on transformer toutes les méthodes ?

### Énoncé

Auto-wrap des méthodes.

Explication
- Parcourir namespace et décorer chaque fonction.

        print("LOG:", fn.__name__)
        return fn(*args, **kwargs)
    return wrapper

class AutoLog(type):

# 15️⃣ Ordre réel d’exécution lors d’une instanciation contrôlée par méta-classe

## Énoncé

Préciser et démontrer l’ordre exact des appels lorsque l’on instancie une classe contrôlée par une méta-classe.

## Solution

```python
"""
Explication
Lorsqu’on exécute instance = Classe():

1) Meta.__call__()
2) Classe.__new__()
3) Classe.__init__()

La méta-classe contrôle entièrement l’instanciation.
"""

class Meta(type):
    def __call__(cls, *args, **kwargs):
        print("1 - Meta.__call__")
        return super().__call__(*args, **kwargs)

class A(metaclass=Meta):
    def __new__(cls):
        print("2 - Classe.__new__")
        return super().__new__(cls)

    def __init__(self):
        print("3 - Classe.__init__")

a = A()
```

Sortie observée :

1 - Meta.**call**  
2 - Classe.**new**  
3 - Classe.**init**

# 16️⃣ Comment implémenter un Singleton propre via méta-classe ?

## Énoncé

Créer un Singleton robuste garantissant une seule instance.

## Solution

```python
"""
Explication
La méta-classe stocke les instances déjà créées.
Si la classe a déjà été instanciée, elle retourne la même instance.
"""

class SingletonMeta(type):
    _instances = {}

    def __call__(cls, *args, **kwargs):
        if cls not in cls._instances:
            print("Création nouvelle instance")
            cls._instances[cls] = super().__call__(*args, **kwargs)
        else:
            print("Réutilisation instance existante")
        return cls._instances[cls]


class Database(metaclass=SingletonMeta):
    def __init__(self):
        print("Initialisation Database")

db1 = Database()
db2 = Database()

print("Même instance :", db1 is db2)
```

Explication

# 20️⃣ Comment implémenter un mini ORM simplifié via méta-classe ?

## Énoncé

Créer un mécanisme qui :

- Enregistre les champs déclarés

- Génère automatiquement une méthode save()

- Maintient un registre global des modèles

## Solution

```python
"""
Explication
La méta-classe :
- détecte les attributs déclarés comme champs
- les stocke dans _fields
- ajoute automatiquement une méthode save()
- enregistre les modèles dans un registre
"""

class Field:
    def __init__(self, type_):
        self.type_ = type_


class ORMMeta(type):
    registry = {}

    def __new__(mcls, name, bases, namespace):

        fields = {}

        for key, value in namespace.items():
            if isinstance(value, Field):
                fields[key] = value.type_

        namespace["_fields"] = fields

        def save(self):
            data = {k: getattr(self, k) for k in self._fields}
            print(f"Saving into table {name}:", data)

        namespace["save"] = save

        cls = super().__new__(mcls, name, bases, namespace)

        if name != "BaseModel":
            mcls.registry[name] = cls

        return cls


class BaseModel(metaclass=ORMMeta):
    pass


class User(BaseModel):
    id = Field(int)
    name = Field(str)

    def __init__(self, id, name):
        self.id = id
        self.name = name


u = User(1, "Ali")
u.save()

print("Registry :", ORMMeta.registry)
print("Champs détectés :", User._fields)
```
