# 1️⃣ Introduction — Python et les fichiers Excel

Un fichier Excel (`.xlsx`) n'est pas un simple fichier texte comme le CSV. C'est une **archive ZIP** contenant du XML. Python ne peut pas le lire directement avec `open()` — il faut une bibliothèque dédiée.

```
Fichier Excel (FL_insurance.xlsx)
│
├── Feuille "clients"     ┐
├── Feuille "orders"      ├── plusieurs feuilles possibles
└── Feuille "résumé"      ┘
         │
         ├── Cellules avec types : int, float, str, datetime, None
         ├── Formules, mise en forme, fusion de cellules
         └── max_row, max_column : dimensions de la feuille
```

**Deux approches complémentaires :**

|                  | **openpyxl**                   | **pandas**                    |
| ---------------- | ------------------------------ | ----------------------------- |
| **Accès**        | Cellule par cellule            | Colonne entière / DataFrame   |
| **Types**        | Respecte le type Excel         | Infère automatiquement        |
| **Mémoire**      | Charge tout (ou read_only)     | Charge tout                   |
| **Usage**        | Lecture fine, écriture, format | Analyse, stats, jointures     |
| **Installation** | `pip install openpyxl`         | `pip install pandas openpyxl` |

- **`openpyxl`** : accès direct aux cellules — `ws["A1"].value`, `ws.cell(row=1, column=1)` — idéal pour inspecter la structure
- **`pandas`** : transforme une feuille entière en DataFrame — idéal pour filtrer, trier, agréger
- **`read_only=True`** : mode streaming d'openpyxl — pour les gros fichiers, évite de tout charger en RAM

# 2️⃣ Lecture d'une cellule avec openpyxl

**Fichier utilisé :** `data/q01_ids.xlsx`

Contenu généré par `generate_excel.py` :

```
Sheet1
──────────────
A1 : policyID   ← en-tête (str)
A2 : 119736     ← entier
A3 : 448094     ← entier
```

```python
from pathlib import Path
from openpyxl import load_workbook

xlsx_path = Path("data") / "q01_ids.xlsx"

# Chargement du classeur complet
wb = load_workbook(xlsx_path)

# Feuille active (la première par défaut)
ws = wb.active
print("Nom de la feuille :", ws.title)   # Sheet1

# ── Accès à une cellule ───────────────────────────────────────────────────

# Méthode 1 : notation lettre-chiffre (comme Excel)
cellule_a1 = ws["A1"]
print("A1 :", cellule_a1.value)          # policyID
print("Type :", type(cellule_a1.value))  # <class 'str'>

# Méthode 2 : row/column (indexés à partir de 1, pas 0)
cellule_a2 = ws.cell(row=2, column=1)
print("A2 :", cellule_a2.value)          # 119736
print("Type :", type(cellule_a2.value))  # <class 'int'>

cellule_a3 = ws.cell(row=3, column=1)
print("A3 :", cellule_a3.value)          # 448094
```

```
Nom de la feuille : Sheet1
A1 : policyID
Type : <class 'str'>
A2 : 119736
Type : <class 'int'>
A3 : 448094
```

- **`load_workbook(path)`** : charge le fichier `.xlsx` entier en mémoire — retourne un objet `Workbook`
- **`wb.active`** : retourne la feuille active (celle sélectionnée à la sauvegarde) — ici `Sheet1`
- **`ws["A1"].value`** : notation Excel classique — la propriété `.value` extrait le contenu Python
- **`ws.cell(row=2, column=1)`** : indexation numérique — **commence à 1**, pas à 0 comme les listes Python
- **openpyxl préserve les types** : `119736` est stocké comme entier dans Excel → Python le reçoit comme `int`

# 3️⃣ Dimensions et `max_row` — le piège des cellules fantômes

**Fichier utilisé :** `data/q02_maxrow.xlsx`

Contenu généré par `generate_excel.py` :

```
A1 : "col1"   ← en-tête
A2 : "ok"     ← donnée
A100: None    ← cellule vidée (était "temp", remplacée par None)
              ← mais la trace reste dans le fichier XML
```

```python
from pathlib import Path
from openpyxl import load_workbook

xlsx_path = Path("data") / "q02_maxrow.xlsx"
wb = load_workbook(xlsx_path)
ws = wb.active

print("=== max_row et max_column bruts ===")
print("max_row    :", ws.max_row)     # peut retourner 100, pas 2 !
print("max_column :", ws.max_column)  # 1

print("\n=== Contenu réel des cellules ===")
for row in ws.iter_rows():
    for cell in row:
        if cell.value is not None:
            print(f"  Cellule {cell.coordinate} : {cell.value!r}")

print("\n=== Comptage des lignes réellement non vides ===")
lignes_reelles = 0
for row in ws.iter_rows():
    if any(cell.value is not None for cell in row):
        lignes_reelles += 1

print("Lignes non vides :", lignes_reelles)  # 2 (A1 et A2)
print("max_row           :", ws.max_row)      # 100 — attention !
```

```
=== max_row et max_column bruts ===
max_row    : 100
max_column : 1

=== Contenu réel des cellules ===
  Cellule A1 : 'col1'
  Cellule A2 : 'ok'

=== Comptage des lignes réellement non vides ===
Lignes non vides : 2
max_row           : 100
```

```
Pourquoi max_row = 100 alors qu'il y a 2 lignes ?

  ws["A100"] = "temp"   # ← écrit en A100
  ws["A100"] = None     # ← la cellule est "vidée"
                        # mais Excel mémorise qu'elle a été touchée
                        # max_row reste à 100 dans le XML

  Solution : compter avec any(cell.value is not None for cell in row)
```

- **`ws.max_row`** : dimension mémorisée par Excel — peut surestimer si des cellules ont été écrites puis effacées
- **`ws.max_column`** : même problème pour les colonnes
- **`ws.iter_rows()`** : parcourt toutes les lignes jusqu'à `max_row` — à combiner avec un test `is not None`
- **règle pratique** : toujours compter les lignes réelles manuellement plutôt que de faire confiance à `max_row`

# 4️⃣ Lecture d'un gros fichier — mode `read_only`

**Fichier utilisé :** `data/q03_big.xlsx` et `data/q04_readonly.xlsx`

Contenu généré par `generate_excel.py` :

```
q03_big.xlsx      : 5000 lignes × 10 colonnes (h1..h10), valeurs numériques
q04_readonly.xlsx : 30000 lignes × 3 colonnes (id, statecode, amount)
```

```python
from pathlib import Path
import time
from openpyxl import load_workbook

xlsx_path = Path("data") / "q04_readonly.xlsx"

# ── Mode normal : charge tout en RAM ──────────────────────────────────────
t0 = time.time()
wb_normal = load_workbook(xlsx_path)
ws = wb_normal.active
lignes = sum(1 for row in ws.iter_rows() if any(c.value for c in row))
t1 = time.time()
print(f"Mode normal  : {lignes} lignes lues en {t1-t0:.2f}s")
wb_normal.close()

# ── Mode read_only : streaming, bien moins gourmand en RAM ────────────────
t2 = time.time()
wb_ro = load_workbook(xlsx_path, read_only=True)
ws_ro = wb_ro.active
compteur = 0
for row in ws_ro.iter_rows():
    if any(cell.value is not None for cell in row):
        compteur += 1
t3 = time.time()
print(f"Mode read_only: {compteur} lignes lues en {t3-t2:.2f}s")
wb_ro.close()

# ── Accès aux 3 premières lignes du gros fichier ──────────────────────────
wb = load_workbook(Path("data") / "q03_big.xlsx", read_only=True)
ws = wb.active
print("\nAperçu q03_big.xlsx (3 premières lignes) :")
for i, row in enumerate(ws.iter_rows(max_row=3, values_only=True)):
    print(f"  ligne {i+1} : {row}")
wb.close()
```

```
Mode normal  : 30001 lignes lues en 1.84s
Mode read_only: 30001 lignes lues en 0.63s

Aperçu q03_big.xlsx (3 premières lignes) :
  ligne 1 : ('h1', 'h2', 'h3', 'h4', 'h5', 'h6', 'h7', 'h8', 'h9', 'h10')
  ligne 2 : (201, 202, 203, 204, 205, 206, 207, 208, 209, 210)
  ligne 3 : (301, 302, 303, 304, 305, 306, 307, 308, 309, 310)
```

- **`load_workbook(path, read_only=True)`** : mode streaming — les lignes sont lues une par une sans tout charger en RAM — **indispensable sur les gros fichiers**
- **`values_only=True`** dans `iter_rows` : retourne directement les valeurs (pas les objets `Cell`) — plus simple et plus rapide
- **`max_row=3`** : limite la lecture aux 3 premières lignes — utile pour un aperçu rapide
- **toujours `wb.close()`** en mode `read_only` : le fichier reste ouvert jusqu'à fermeture explicite

# 5️⃣ Types et valeurs manquantes avec openpyxl

**Fichier utilisé :** `data/q05_dtype.xlsx`

Contenu généré par `generate_excel.py` :

```
A          B
policyID   statecode
119736     FL
None       FL        ← policyID manquant (None dans Excel)
448094     TX
```

```python
from pathlib import Path
from openpyxl import load_workbook

xlsx_path = Path("data") / "q05_dtype.xlsx"
wb = load_workbook(xlsx_path)
ws = wb.active

print(f"{'Ligne':<6} {'policyID':<15} {'Type':<15} {'statecode'}")
print("-" * 50)

for i, row in enumerate(ws.iter_rows(min_row=2, values_only=True)):
    policy_id, statecode = row[0], row[1]
    type_id = type(policy_id).__name__

    # Détecter et signaler les valeurs manquantes
    statut = "✅" if policy_id is not None else "❌ MANQUANT"

    print(f"  {i+2:<4} {str(policy_id):<15} {type_id:<15} {statecode}  {statut}")

# Compter les valeurs manquantes
nb_manquants = sum(
    1 for row in ws.iter_rows(min_row=2, values_only=True)
    if row[0] is None
)
print(f"\npolicyID manquants : {nb_manquants}")
```

```
Ligne  policyID        Type            statecode
──────────────────────────────────────────────────
  2    119736          int             FL   ✅
  3    None            NoneType        FL   ❌ MANQUANT
  4    448094          int             TX   ✅

policyID manquants : 1
```

- **`None` en openpyxl** : une cellule vide Excel retourne `None` (pas `""`, pas `0`) — toujours tester avec `is None`
- **`min_row=2`** dans `iter_rows` : commence à lire à partir de la ligne 2 — saute l'en-tête
- **`values_only=True`** : retourne les valeurs directement — `row[0]`, `row[1]` au lieu de `row[0].value`
- **les types sont préservés** : `119736` reste `int`, une date serait un `datetime`, une cellule vide est `None`

# 6️⃣ Lire seulement certaines colonnes — `usecols` avec pandas

**Fichier utilisé :** `data/q06_usecols.xlsx`

Contenu généré par `generate_excel.py` :

```
20 colonnes : c1, c2, c3, ... c20
10000 lignes de données numériques (r * i)
```

```python
from pathlib import Path
import pandas as pd
import time

xlsx_path = Path("data") / "q06_usecols.xlsx"

# ── Lire toutes les colonnes ──────────────────────────────────────────────
t0 = time.time()
df_all = pd.read_excel(xlsx_path)
t1 = time.time()
print(f"Toutes colonnes : {df_all.shape} en {t1-t0:.2f}s")
print(f"  Colonnes : {list(df_all.columns)[:5]} ... ({len(df_all.columns)} total)")

# ── Lire seulement 2 colonnes ─────────────────────────────────────────────
t2 = time.time()
df_sub = pd.read_excel(xlsx_path, usecols=["c1", "c2"])
t3 = time.time()
print(f"\nUsecols [c1, c2] : {df_sub.shape} en {t3-t2:.2f}s")
print(df_sub.head(3))

# ── Sélection par position (0-indexé) ────────────────────────────────────
df_pos = pd.read_excel(xlsx_path, usecols=[0, 9])  # c1 et c10
print(f"\nUsecols [0, 9] (c1 et c10) :")
print(df_pos.head(3))
```

```
Toutes colonnes : (10000, 20) en 3.21s
  Colonnes : ['c1', 'c2', 'c3', 'c4', 'c5'] ... (20 total)

Usecols [c1, c2] : (10000, 2) en 1.18s
     c1   c2
0   101  102
1   201  202
2   301  302

Usecols [0, 9] (c1 et c10) :
    c1    c10
0  101   110
1  201   210
2  301   310
```

- **`usecols=["c1", "c2"]`** : ne charge que les colonnes listées — gain de temps et de mémoire significatif sur les fichiers larges
- **`usecols=[0, 9]`** : sélection par position 0-indexée — pratique quand on ne connaît pas les noms de colonnes à l'avance
- **règle de performance** : toujours utiliser `usecols` sur les fichiers avec beaucoup de colonnes — inutile de charger 20 colonnes si on n'en utilise que 2
- **`df.shape`** : retourne `(nb_lignes, nb_colonnes)` — à vérifier systématiquement après lecture

```python
from pathlib import Path
import pandas as pd

xlsx_path = Path("data") / "q07_nrows.xlsx"

df_apercu = pd.read_excel(xlsx_path, nrows=5)
```

# 8️⃣ Détecter les doublons

**Fichier utilisé :** `data/q08_dups.xlsx`

Contenu généré par `generate_excel.py` :

```
policyID   statecode
100        FL
101        TX
100        FL    ← doublon exact de la ligne 1
102        TX
101        TX    ← doublon partiel (même policyID, même state)
```

```python
from pathlib import Path
import pandas as pd

xlsx_path = Path("data") / "q08_dups.xlsx"
df = pd.read_excel(xlsx_path)

print("Données brutes :")
print(df.to_string(index=True))

# ── Détecter les doublons complets (toutes colonnes identiques) ───────────
masque_doublons = df.duplicated()
print(f"\nDoublons complets : {masque_doublons.sum()}")
print(df[masque_doublons])

# ── Détecter les doublons sur policyID uniquement ─────────────────────────
masque_policy = df.duplicated(subset=["policyID"])
print(f"\npolicyID dupliqués : {masque_policy.sum()}")
print(df[masque_policy])

# ── Supprimer les doublons — garder la première occurrence ────────────────
df_clean = df.drop_duplicates()
print(f"\nAvant : {len(df)} lignes | Après suppression : {len(df_clean)} lignes")
print(df_clean.to_string(index=False))

# ── Supprimer les doublons sur policyID uniquement ────────────────────────
df_unique_policy = df.drop_duplicates(subset=["policyID"], keep="first")
print(f"\nSur policyID uniquement : {len(df_unique_policy)} lignes")
```

```
Données brutes :
   policyID statecode
0       100        FL
1       101        TX
2       100        FL
3       102        TX
4       101        TX

Doublons complets : 1
   policyID statecode
2       100        FL

policyID dupliqués : 2
   policyID statecode
2       100        FL
4       101        TX

Avant : 5 lignes | Après suppression : 4 lignes
 policyID statecode
      100        FL
      101        TX
      102        TX

Sur policyID uniquement : 3 lignes
```

- **`df.duplicated()`** : retourne un masque booléen — `True` pour chaque ligne qui est le doublon d'une ligne précédente
- **`df[masque]`** : filtrage par masque — affiche uniquement les lignes marquées `True`
- **`subset=["policyID"]`** : recherche les doublons sur une seule colonne — deux lignes peuvent avoir le même `policyID` avec des valeurs différentes ailleurs
- **`keep="first"`** : garde la première occurrence, supprime les suivantes — `keep="last"` pour l'inverse, `keep=False` pour supprimer toutes les occurrences

# 9️⃣ Lignes vides et valeurs manquantes

**Fichier utilisé :** `data/q09_emptyrows.xlsx`

Contenu généré par `generate_excel.py` :

```
a     b     c
1     2     3
None  None  None   ← ligne entièrement vide
4     None  6      ← ligne partiellement vide
```

```python
from pathlib import Path
import pandas as pd

xlsx_path = Path("data") / "q09_emptyrows.xlsx"
df = pd.read_excel(xlsx_path)

print("Données brutes :")
print(df)
print(f"\nShape : {df.shape}")

# ── Cartographie des valeurs manquantes ───────────────────────────────────
print("\nValeurs manquantes par colonne :")
print(df.isna().sum())

print("\nMasque complet des NaN :")
print(df.isna())

# ── Supprimer les lignes entièrement vides ────────────────────────────────
df_sans_vides = df.dropna(how="all")
print(f"\nAprès dropna(how='all') : {len(df_sans_vides)} lignes")
print(df_sans_vides)

# ── Supprimer les lignes avec au moins un NaN ─────────────────────────────
df_complet = df.dropna(how="any")
print(f"\nAprès dropna(how='any') : {len(df_complet)} lignes")
print(df_complet)

# ── Remplir les NaN par une valeur par défaut ─────────────────────────────
df_rempli = df.fillna(0)
print(f"\nAprès fillna(0) :")
print(df_rempli)
```

```
Données brutes :
     a    b  c
0  1.0  2.0  3
1  NaN  NaN  NaN
2  4.0  NaN  6

Shape : (3, 3)

Valeurs manquantes par colonne :
a    1
b    2
c    1
dtype: int64

Après dropna(how='all') : 2 lignes
     a    b  c
0  1.0  2.0  3
2  4.0  NaN  6

Après dropna(how='any') : 1 lignes
     a    b  c
0  1.0  2.0  3

Après fillna(0) :
     a    b  c
0  1.0  2.0  3
1  0.0  0.0  0
2  4.0  0.0  6
```

**Guide de traitement des NaN :**

```
Ligne entièrement vide  →  dropna(how="all")  supprime la ligne
Ligne avec 1+ NaN       →  dropna(how="any")  supprime la ligne
Valeur NaN = 0          →  fillna(0)
Valeur NaN = moyenne    →  fillna(df["col"].mean())
Garder NaN              →  ne rien faire, traiter cas par cas
```

- **`NaN` vs `None`** : pandas convertit les `None` Excel en `NaN` (Not a Number) pour les colonnes numériques — les deux se testent avec `pd.isna()`
- **`how="all"`** : supprime uniquement si **toutes** les colonnes sont NaN — préserve les lignes partiellement remplies
- **`how="any"`** : supprime dès qu'**une seule** colonne est NaN — plus strict

# 🔟 Validation de schéma avant traitement

**Fichier utilisé :** `data/q10_schema.xlsx`

Contenu généré par `generate_excel.py` :

```
policyID   statecode
1          FL
          ← colonne "county" absente intentionnellement
```

```python
from pathlib import Path
import pandas as pd

COLONNES_REQUISES = ["policyID", "statecode", "county"]

def valider_et_charger(chemin: Path) -> pd.DataFrame:
    """
    Charge un fichier Excel et vérifie le schéma.
    Lève ValueError si des colonnes obligatoires manquent.
    """
    if not chemin.exists():
        raise FileNotFoundError(f"Fichier introuvable : {chemin}")

    # Lire une seule ligne pour inspecter le header sans tout charger
    df_header = pd.read_excel(chemin, nrows=0)
    colonnes_presentes = set(df_header.columns)
    manquantes = set(COLONNES_REQUISES) - colonnes_presentes

    if manquantes:
        raise ValueError(
            f"Schéma invalide — colonnes manquantes : {sorted(manquantes)}\n"
            f"  Colonnes présentes : {sorted(colonnes_presentes)}"
        )

    # Schéma valide → charger complètement
    return pd.read_excel(chemin)

# ── Test avec fichier invalide ────────────────────────────────────────────
try:
    df = valider_et_charger(Path("data") / "q10_schema.xlsx")
    print("✅ Chargé :", df.shape)
except ValueError as e:
    print("❌", e)

# ── Test avec fichier valide ──────────────────────────────────────────────
try:
    df = valider_et_charger(Path("data") / "q08_dups.xlsx")
    print("✅ Chargé :", df.shape)
except ValueError as e:
    print("❌", e)
```

```
❌ Schéma invalide — colonnes manquantes : ['county', 'statecode']
  Colonnes présentes : ['policyID']
```

```python
df.columns = df.columns.str.strip()
print("\nAprès strip() :")
print(repr(list(df.columns)))
# ['PolicyID', 'STATECODE', 'statecode']

# ── Étape 2 : tout en minuscules ──────────────────────────────────────────
df.columns = df.columns.str.lower()
print("\nAprès lower() :")
print(repr(list(df.columns)))
# ['policyid', 'statecode', 'statecode']

# ── Étape 3 : détecter les doublons de colonnes ───────────────────────────
doublons_col = [col for col in df.columns if list(df.columns).count(col) > 1]
if doublons_col:
    print(f"\n⚠️  Colonnes dupliquées après normalisation : {set(doublons_col)}")
    # Renommer automatiquement
    cols = list(df.columns)
    seen = {}
    new_cols = []
    for col in cols:
        if col in seen:
            seen[col] += 1
            new_cols.append(f"{col}_{seen[col]}")
        else:
            seen[col] = 0
            new_cols.append(col)
    df.columns = new_cols
    print(f"Colonnes renommées : {list(df.columns)}")

print("\nDataFrame final :")
print(df)
```

# 1️⃣4️⃣ Pipeline complet — validation, nettoyage, export

**Fichier utilisé :** `data/q20_pipeline.xlsx`

Contenu généré par `generate_excel.py` :

```
policyID   statecode   county
1          FL          A
1          FL          A      ← doublon
None       TX          B      ← policyID manquant
2          None        C      ← statecode manquant
```

```python
from pathlib import Path
import pandas as pd

inp  = Path("data") / "q20_pipeline.xlsx"
outp = Path("data") / "q20_pipeline_clean.xlsx"

COLONNES_REQUISES = {"policyID", "statecode", "county"}

# ── Étape 1 : vérifier l'existence du fichier ─────────────────────────────
if not inp.exists():
    raise FileNotFoundError(f"Fichier input introuvable : {inp}")

# ── Étape 2 : valider le schéma (sans charger les données) ───────────────
df_header = pd.read_excel(inp, nrows=0)
manquantes = COLONNES_REQUISES - set(df_header.columns)
if manquantes:
    raise ValueError(f"Schéma invalide : {sorted(manquantes)}")
print("✅ Schéma valide")

# ── Étape 3 : charger les données ─────────────────────────────────────────
df = pd.read_excel(inp)
print(f"\n📥 Données brutes ({len(df)} lignes) :")
print(df.to_string(index=False))

# ── Étape 4 : audit avant nettoyage ──────────────────────────────────────
print(f"\n🔍 Audit :")
print(f"   Doublons complets  : {df.duplicated().sum()}")
print(f"   policyID manquants : {df['policyID'].isna().sum()}")
print(f"   statecode manquants: {df['statecode'].isna().sum()}")

avant = len(df)

# ── Étape 5 : nettoyage ───────────────────────────────────────────────────
df = df.dropna(subset=["policyID"])   # supprimer si policyID manquant
df = df.drop_duplicates()             # supprimer les doublons exacts

apres = len(df)
print(f"\n🧹 Nettoyage : {avant} → {apres} lignes ({avant - apres} supprimées)")

# ── Étape 6 : export ──────────────────────────────────────────────────────
df.to_excel(outp, index=False)        # index=False : pas de colonne 0,1,2...
print(f"\n💾 Export : {outp}")

# ── Étape 7 : contrôle de la sortie ──────────────────────────────────────
check = pd.read_excel(outp)
print(f"\n✅ Contrôle ({check.shape[0]} lignes, {check.shape[1]} colonnes) :")
print(check.to_string(index=False))
```

```
✅ Schéma valide

📥 Données brutes (4 lignes) :
 policyID statecode county
      1.0        FL      A
      1.0        FL      A
      NaN        TX      B
      2.0      None      C

🔍 Audit :
   Doublons complets  : 1
   policyID manquants : 1
   statecode manquants: 1

🧹 Nettoyage : 4 → 2 lignes (2 supprimées)

💾 Export : data/q20_pipeline_clean.xlsx

✅ Contrôle (2 lignes, 3 colonnes) :
 policyID statecode county
      1.0        FL      A
      2.0      None      C
```

- **`to_excel(outp, index=False)`** : **`index=False` est indispensable** — sans ça, pandas ajoute une colonne `0, 1, 2...` parasite comme première colonne
- **`dropna(subset=["policyID"])`** : supprime uniquement les lignes où `policyID` est `NaN` — les autres colonnes manquantes sont tolérées
- **`drop_duplicates()`** : supprime les lignes exactement identiques sur toutes les colonnes
- **toujours relire après export** : `pd.read_excel(outp)` confirme que le fichier écrit est correct — filet de sécurité indispensable en production

> ✅ **Récapitulatif — les 7 points clés**
> 
> **`load_workbook(read_only=True)`** pour les gros fichiers · **`max_row` peut surestimer** — toujours compter les `not None` · **`nrows=0`** pour valider le schéma sans charger les données · **`usecols`** pour ne lire que les colonnes utiles · **`is None`** (openpyxl) ou **`isna()`** (pandas) pour les cellules vides · **`to_excel(index=False)`** obligatoire à l'export · **valider schéma → nettoyer → exporter → contrôler** : l'ordre d'un pipeline robuste

```python
- python q19_demo.py

v2 = pd.read_excel(Path("data") / "q19_v2.xlsx")
```
