# 1️⃣ Pourquoi modulariser un projet ?

Dans un projet réel :

- Séparation des responsabilités

- Réduction du couplage

- Réutilisabilité

- Maintenabilité

- Tests unitaires simplifiés

- Déploiement structuré

Un module est une unité logique de code.
Un package est un regroupement hiérarchique de modules.

# 2️⃣ Module : définition concrète

Un module est simplement un fichier `.py`.

Tout au long de ce document, nous construisons progressivement une application de gestion de stock **StockPro**.

```
stockpro/
    operations.py
    main.py
```

**operations.py**

```python
"""
Module d'opérations pour la gestion de stock StockPro.
Expose des fonctions réutilisables de calcul.
"""

def total_stock(quantite, prix_unitaire):
    """Calcule la valeur totale d'un article en stock."""
    return quantite * prix_unitaire

def appliquer_remise(prix, taux):
    """Applique une remise sur un prix. taux entre 0 et 1."""
    return prix * (1 - taux)

TVA = 0.20
```

**main.py**

```python
"""
Script principal StockPro utilisant le module operations.
"""

import operations

valeur = operations.total_stock(50, 12.99)
prix_remise = operations.appliquer_remise(valeur, 0.10)

print(f"Valeur stock    : {valeur:.2f} €")
print(f"Après remise    : {prix_remise:.2f} €")
print(f"TVA appliquée   : {operations.TVA}")
```

# 3️⃣ Les différentes formes d'import

```python
"""
Quatre formes d'import — chacune avec son cas d'usage.
"""

# Import complet — accès via namespace
import operations
print(operations.TVA)

# Import ciblé — accès direct
from operations import total_stock
print(total_stock(10, 5.99))

# Import avec alias — raccourci pratique
import operations as ops
print(ops.appliquer_remise(100, 0.15))

# Import élément avec alias
from operations import total_stock as calculer
print(calculer(20, 3.50))

# À éviter — pollution d'espace de noms
# from operations import *
```

# 7️⃣ Organisation en Package

Un package est un dossier contenant un fichier `__init__.py`. `__init__.py` initialise le package et définit son API publique.

```
stockpro/
    __init__.py
    produits.py
    fournisseurs.py
    commandes.py
```

**produits.py**

```python
def ajouter_produit(nom: str, prix: float) -> dict:
    """Crée un produit StockPro."""
    return {"nom": nom, "prix": prix, "stock": 0}
```

****init**.py**

```python
"""
Package StockPro — point d'entrée principal.

__init__.py remplit trois rôles :
1. Signale à Python que ce dossier est un package
2. Initialise le package (imports, config, hooks)
3. Définit l'API publique via __all__

Ce code s'exécute UNE SEULE FOIS au premier import du package.
"""

from .produits     import ajouter_produit
from .commandes    import passer_commande

__all__ = ["ajouter_produit", "passer_commande"]

print("Package StockPro initialisé")    # visible au premier import
```

**Utilisation**

```python
from stockpro import ajouter_produit

p = ajouter_produit("Clavier", 49.99)
print(p)
```

**repository.py**

```python
Accès aux données — couche repository.

def get_produits() -> list:
    """Simule un accès base de données."""
    return [
        {"nom": "Clavier",  "prix": 49.99, "stock": 120},
        {"nom": "Souris",   "prix": 29.99, "stock": 85},
        {"nom": "Écran",    "prix": 249.99, "stock": 30},
    ]
```

**services.py**

```python
"""
Logique métier — couche services.
"""

from .repository import get_produits

def produits_en_alerte(seuil: int = 50) -> list:
    """Retourne les produits dont le stock est sous le seuil."""
    return [p for p in get_produits() if p["stock"] < seuil]

def valeur_totale_stock() -> float:
    """Calcule la valeur totale du stock."""
    return sum(p["prix"] * p["stock"] for p in get_produits())
```

```python
    print("=== Rapport StockPro ===")
    print(f"Valeur totale : {valeur_totale_stock():.2f} €")
    print("\nAlertes stock :")
    for p in produits_en_alerte(seuil=50):
```

- Documenter chaque module avec une docstring en tête de fichier

- Ne jamais exécuter de logique lourde au niveau global — encapsuler dans des fonctions

- Centraliser la configuration dans `config.py`

- Séparer l'accès aux données (repository) de la logique métier (services)

# 2️⃣0️⃣ Synthèse

- Module = fichier `.py` — unité logique de code

- Package = dossier avec `__init__.py` — regroupement hiérarchique

- `__init__.py` initialise le package et définit son API publique via `__all__`

- `__name__ == "__main__"` protège le code d'entrée à l'import

- `sys.path` détermine où Python cherche les modules

- Préférer l'import absolu — plus stable et plus lisible

- Ne jamais nommer un fichier comme un module standard (`math.py`, `os.py`)

- Séparer repository (accès données) et services (logique métier)

- Centraliser la configuration dans `config.py` avec `os.getenv`

- `src/` isole le code source et simule une installation réelle

# 1) Pourquoi éviter `from module import *` ?

## Énoncé

Pourquoi cette forme d'import peut provoquer des bugs difficiles à détecter ?

## Solution

```
stockpro/
    entrepot_paris.py
    entrepot_lyon.py
```

```python
Explication :
from module import * injecte tous les noms publics
dans l'espace courant.
Risque de collision silencieuse entre modules.

stock = 150

# Correct — namespace explicite
import entrepot_paris as paris
import entrepot_lyon  as lyon

print(paris.stock)    # 150
print(lyon.stock)     # 80
```

# 11) Rechargement — piège courant

## Énoncé

Pourquoi `importlib.reload` ne met pas toujours à jour les références ?

## Solution

```python
"""
Explication :
reload met à jour l'objet module dans sys.modules.
Mais les références déjà extraites via from ... import
pointent toujours vers l'ancien objet.
"""

import importlib
import stockpro.repository as repo

# Après modification de repository.py
importlib.reload(repo)
print("Module rechargé :", repo.get_all())    # ✅ à jour

# Piège — référence directe non mise à jour
from stockpro.repository import get_all
importlib.reload(repo)
print("Référence directe :", get_all())    # ❌ ancienne version
```

```python
# facturation/calculs.py
"""
Calculs de facturation StockPro.
"""

def calculer_ttc(prix_ht: float, taux_tva: float = 0.20) -> float:
    """Calcule le prix TTC depuis un prix HT."""
    return round(prix_ht * (1 + taux_tva), 2)

def appliquer_remise(prix: float, taux: float) -> float:
    """Applique une remise. taux entre 0 et 1."""
    return round(prix * (1 - taux), 2)
```

```python
# facturation/rapport.py
"""
Génération de rapports de facturation.
"""

from .calculs import calculer_ttc, appliquer_remise

def generer_rapport(produits: list) -> None:
    """Affiche un rapport TTC pour une liste de produits."""
    print("=== Rapport Facturation StockPro ===")
    total = 0
    for p in produits:
        ttc = calculer_ttc(p["prix_ht"])
        total += ttc
        print(f"  {p['nom']:20} HT: {p['prix_ht']:.2f}€  TTC: {ttc:.2f}€")
    print(f"{'Total TTC':>35} {total:.2f}€")
```
