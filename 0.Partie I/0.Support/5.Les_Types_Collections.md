

# Les Types de Collections en Python

Le support est une propriété de **Bechir Bejaoui**

---

Les collections permettent de regrouper, organiser et manipuler plusieurs données au sein d'une même structure.
Chaque type possède des propriétés spécifiques adaptées à des usages précis en développement professionnel.

Les principales collections en Python sont :

- Les listes

- Les tuples

- Les dictionnaires

- Les ensembles

- Les tableaux typés

---

# 1️⃣ Les Listes

Une liste est une séquence ordonnée et modifiable d'éléments.
Elle accepte des types hétérogènes et autorise la duplication.

## Création d'une liste

```python
"""
Création d'une liste simple et d'une liste hétérogène.
"""

nombres = [10, 20, 30, 40]
mixte = [1, "Python", True, 3.14]

print(nombres)
print(mixte)
```

## Accès aux éléments

```python
"""
Indexation positive et négative.
"""

print(nombres[0])       # Premier élément
print(nombres[-1])      # Dernier élément

nested = [1, [2, 3], 4]
print(nested[1][0])     # Accès imbriqué
```

## Slicing

```python
"""
Extraction de portions avec pas personnalisé.
"""

liste = [1, 2, 3, 4, 5, 6, 7]

print(liste[1:4])     # Extraction
print(liste[::2])     # Un élément sur deux
print(liste[::-1])    # Inversion
```

## Modification

```python
"""
Modification, ajout, insertion et suppression d'éléments.
"""

liste = [1, 2, 3]

liste[1] = 200        # Modifier
liste.append(4)       # Ajouter en fin
liste.insert(0, 0)    # Insérer à l'index 0
liste.remove(200)     # Supprimer par valeur

print(liste)
```

## Compréhensions de listes

```python
"""
Syntaxe concise pour générer des listes.
Ce mécanisme sera approfondi en Partie II.
"""

carres = [x**2 for x in range(1, 11)]
pairs = [x for x in range(20) if x % 2 == 0]

print(carres)
print(pairs)
```

# 2️⃣ Les Tuples

Un tuple est une séquence ordonnée mais immuable.

Il est utilisé pour représenter des données fixes ou des retours multiples.

## Création

```python
"""
Différentes formes de création d'un tuple.
"""

coordonnees = (10, 20)
point = 5, 6           # Sans parenthèses
unique = (100,)        # Tuple à un seul élément — virgule obligatoire

print(coordonnees)
print(unique)
```

## Immutabilité

```python
"""
Toute tentative de modification provoque une erreur.
"""

t = (1, 2, 3)

try:
    t[0] = 10
except TypeError as e:
    print("Erreur :", e)
```

## Unpacking

```python
"""
Déstructuration d'un tuple retourné par une fonction.
"""

def get_user():
    return "Alice", 30

nom, age = get_user()

print(nom)
print(age)
```

# 3️⃣ Les Dictionnaires

Un dictionnaire stocke des paires clé-valeur.
Les clés doivent être immuables.

## Création

```python
"""
Création d'un dictionnaire avec types variés.
"""

user = {
    "nom": "Alice",
    "age": 30,
    "actif": True
}

print(user)
```

## Accès et modification

```python
"""
Lecture, modification et ajout de clés.
"""

print(user["nom"])

user["age"] = 31
user["email"] = "alice@test.com"

print(user)
```

## Méthodes keys, values, items

```python
"""
Accès aux clés, valeurs et paires.
Ces méthodes sont les plus utilisées en parcours.
"""

print(user.keys())     # Toutes les clés
print(user.values())   # Toutes les valeurs
print(user.items())    # Paires clé-valeur
```

## Parcours

```python
"""
Itération sur les paires clé-valeur.
"""

for cle, valeur in user.items():
    print(cle, "->", valeur)
```

## Méthode sécurisée get()

```python
"""
get() retourne une valeur par défaut si la clé est absente.
Évite un KeyError.
"""

print(user.get("adresse", "Non définie"))
```

# 4️⃣ Les Ensembles

Un ensemble est une collection non ordonnée et sans doublons.

## Création

```python
"""
Création d'un set et d'un set vide.
"""

s = {1, 2, 3, 3, 4}    # Les doublons sont automatiquement supprimés
print(s)

vide = set()            # set() et non {} qui crée un dict vide
print(vide)
```

## Opérations ensemblistes

```python
"""
Les quatre opérations fondamentales sur les ensembles.
"""

A = {1, 2, 3}
B = {3, 4, 5}

print(A | B)    # Union
print(A & B)    # Intersection
print(A - B)    # Différence
print(A ^ B)    # Différence symétrique
```

## Méthodes — discard vs remove

```python
"""
add ajoute un élément.
remove supprime un élément — lève une exception si absent.
discard supprime un élément — silencieux si absent.
"""

s = {1, 2, 3}

s.add(10)
s.remove(2)
s.discard(99)    # Pas d'erreur même si 99 est absent

try:
    s.remove(99)
except KeyError as e:
    print("Erreur remove :", e)

print(s)
```

# 5️⃣ Les Tableaux Typés (array)

Les tableaux permettent de stocker des données homogènes de manière plus efficace en mémoire.

## Création

```python
"""
Un array n'accepte qu'un seul type de données.
Plus économe en mémoire qu'une liste pour les données numériques.
"""

from array import array

tab = array("i", [1, 2, 3, 4])    # "i" = entiers signés
print(tab)

tab.append(5)
print(tab)
```

## Contrainte de type

```python
"""
Toute tentative d'ajout d'un type incompatible provoque une erreur.
"""

try:
    tab.append("texte")
except TypeError as e:
    print("Erreur :", e)
```

# Synthèse

- Une liste est ordonnée, mutable, hétérogène

- Un tuple est ordonné, immuable — idéal pour données fixes et retours multiples

- Un dictionnaire stocke des paires clé-valeur — clés immuables obligatoires

- Un set est non ordonné, sans doublons — puissant pour opérations ensemblistes

- `discard` est plus sûr que `remove` sur un set

- `get()` est plus sûr que l'indexation directe sur un dict

- `copy()` est superficielle — utiliser `deepcopy()` pour structures imbriquées

# 1) Pourquoi modifier une liste copiée peut aussi modifier l'originale ?

## Énoncé

Comprendre la différence entre copie superficielle et référence.

## Solution

```python
"""
Explication
L'affectation simple ne crée pas une nouvelle liste
mais une référence vers le même objet en mémoire.
"""

liste1 = [1, 2, 3]
liste2 = liste1    # référence vers le même objet

liste2.append(4)

print("Liste1 :", liste1)
print("Liste2 :", liste2)
print("Même objet mémoire ?", id(liste1) == id(liste2))
```

# 2) Comment créer une vraie copie indépendante d'une liste ?

## Énoncé

Corriger le problème précédent.

## Solution

```python
"""
Explication
copy() crée une nouvelle liste indépendante.
Les modifications n'affectent plus l'originale.
"""

liste1 = [1, 2, 3]
liste2 = liste1.copy()

liste2.append(4)

print("Liste1 :", liste1)
print("Liste2 :", liste2)
print("Même objet mémoire ?", id(liste1) == id(liste2))
```

# 3) Pourquoi une liste contenant une sous-liste reste liée malgré copy() ?

## Énoncé

Comprendre la limite de la copie superficielle.

## Solution

```python
"""
Explication
copy() duplique la structure externe uniquement.
Les sous-objets restent partagés entre les deux listes.
"""

liste1 = [[1, 2], [3, 4]]
liste2 = liste1.copy()

liste2[0].append(99)

print("Liste1 :", liste1)
print("Liste2 :", liste2)
```

# 4) Comment faire une vraie copie profonde ?

## Énoncé

Résoudre le problème des objets imbriqués.

## Solution

```python
"""
Explication
deepcopy copie récursivement tous les sous-objets.
L'original n'est plus affecté.
"""

from copy import deepcopy

liste1 = [[1, 2], [3, 4]]
liste2 = deepcopy(liste1)

liste2[0].append(99)

print("Liste1 :", liste1)
print("Liste2 :", liste2)
```

# 10) Comment trier un dictionnaire par valeur ?

## Énoncé

Réaliser un tri personnalisé.

## Solution

```python

Explication

dict() reconstruit le résultat.
```

# 20) Cas complet : Gestion d'inventaire

## Énoncé

Utiliser plusieurs collections ensemble.

## Solution

```python
"""
Explication
Simulation d'un mini système d'inventaire.
Dictionnaire pour le stock.
Liste de tuples pour les transactions.
"""

stock = {
    "Laptop": 10,
    "Mouse": 25
}

transactions = [
    ("Laptop", -2),
    ("Mouse", -5),
    ("Laptop", 5)
]

for produit, quantite in transactions:
    if produit in stock:
        stock[produit] += quantite

print("Stock final :", stock)
```
