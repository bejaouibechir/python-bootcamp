# MiniStock – Papeterie Express

## Objectif

Créer la structure de base du projet et implémenter une première version très simple du programme de gestion de stock.

---

# Notions abordées dans ce milestone

Avant de commencer cet atelier, il est utile de savoir **ce que vous allez découvrir et pratiquer** dans cette première étape du projet fil rouge.

Dans ce milestone, vous allez découvrir :

- création de la **structure d’un projet Python**

- rôle d’un **fichier README** dans un projet logiciel

- utilisation d’un **fichier requirements.txt**

- création et activation d’un **environnement virtuel Python**

- exécution d’un **script Python depuis la ligne de commande**

- déclaration et utilisation des **variables Python**

- manipulation de **valeurs numériques** (prix, quantités, TVA)

- réalisation de **calculs simples** dans un programme

- utilisation de **print pour afficher des informations**

- introduction au **formatage avec f-strings**

- modélisation simple d’un **stock de produits**

- compréhension du fonctionnement d’un **projet évolutif par versions**

Cette première version constitue **la base du projet MiniStock**.  
À chaque chapitre de la formation, le programme sera enrichi pour ajouter de nouvelles fonctionnalités.

# 1. Création de la structure du projet

Dans le dossier principal de la formation, créez le dossier **projet_fil_rouge** avec la structure suivante :


# 2. Contenu du fichier ministock_v0.py

Créer le fichier **ministock_v0.py**

```python
# MiniStock – Papeterie Express
# Version 0 – Introduction

print("======================================")
print("   BIENVENUE DANS MiniStock !")
print("   Gestion de stock – Papeterie Express")
print("   Tunis – Mars 2026")
print("======================================\n")

# Nom de la boutique
nom_boutique = "Papeterie Bejaoui"

# Informations produit
prix_cahier_ht = 3.50
quantite_initiale_cahiers = 45

# TVA
taux_tva = 0.19

# Calculs
prix_cahier_ttc = prix_cahier_ht * (1 + taux_tva)
valeur_stock_cahiers = prix_cahier_ht * quantite_initiale_cahiers

# Affichage des informations
print(f"Bienvenue à la {nom_boutique}")
print(f"Prix d'un cahier HT       : {prix_cahier_ht:.2f} TND")
print(f"Prix d'un cahier TTC      : {prix_cahier_ttc:.2f} TND")
print(f"Stock initial cahiers     : {quantite_initiale_cahiers} unités")
print(f"Valeur du stock cahiers   : {valeur_stock_cahiers:.2f} TND\n")

print("Projet initialisé.")
print("Ce script sera enrichi à chaque étape de la formation.")
```

# Défi facultatif

Ajoutez dans le script :

- un deuxième article (exemple : **stylo bleu** à **1.20 TND**, **120 unités**)

- son **prix TTC**

- sa **valeur de stock**

- la **valeur totale du stock**

Puis exécutez à nouveau le script.

---

# Solution du défi facultatif

Créer ou modifier le fichier **ministock_v0.py**

```python
print("======================================")
print("   BIENVENUE DANS MiniStock !")
print("   Gestion de stock – Papeterie Express")
print("   Tunis – Mars 2026")
print("======================================\n")

nom_boutique = "Papeterie Bejaoui"

taux_tva = 0.19

# Cahiers
prix_cahier_ht = 3.50
quantite_cahiers = 45

prix_cahier_ttc = prix_cahier_ht * (1 + taux_tva)
valeur_stock_cahiers = prix_cahier_ht * quantite_cahiers

# Stylos
prix_stylo_ht = 1.20
quantite_stylos = 120

prix_stylo_ttc = prix_stylo_ht * (1 + taux_tva)
valeur_stock_stylos = prix_stylo_ht * quantite_stylos

# Valeur totale
valeur_stock_total = valeur_stock_cahiers + valeur_stock_stylos

print(f"Bienvenue à la {nom_boutique}\n")

print("=== Cahiers ===")
print(f"Prix HT : {prix_cahier_ht:.2f} TND")
print(f"Prix TTC : {prix_cahier_ttc:.2f} TND")
print(f"Quantité : {quantite_cahiers}")
print(f"Valeur stock : {valeur_stock_cahiers:.2f} TND\n")

print("=== Stylos ===")
print(f"Prix HT : {prix_stylo_ht:.2f} TND")
print(f"Prix TTC : {prix_stylo_ttc:.2f} TND")
print(f"Quantité : {quantite_stylos}")
print(f"Valeur stock : {valeur_stock_stylos:.2f} TND\n")

print(f"Valeur totale du stock : {valeur_stock_total:.2f} TND")
```
