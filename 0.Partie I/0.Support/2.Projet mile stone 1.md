**MiniStock – Papeterie Express**  
(après l’atelier 1 – Opérations mathématiques de base)

**Objectif**  
Créer la structure de base du projet et implémenter une première version très simple du programme de gestion de stock.

**1. Création de la structure du projet**

Dans le dossier principal de la formation, créez le dossier `projet_fil_rouge` avec la structure suivante :

```
formation-python/
└── projet_fil_rouge/
    ├── README.md
    ├── requirements.txt
    └── ministock_v0.py
```

**Contenu du fichier README.md**

```markdown
# MiniStock – Papeterie Express

Projet fil rouge de la formation Python.

**Contexte**  
Gestion du stock d’une petite papeterie à Tunis.

**Progression prévue**  
- v0 : introduction et squelette de base  
- v1 : utilisation des collections (après chapitre 4)  
- v2 : dates et conditions (après chapitre 8)  
- v3 : itérations et affichages (après chapitre 9)

**2. Contenu du fichier ministock_v0.py**

```python
# ministock_v0.py
# MiniStock – Papeterie Express
# Version 0 – Introduction

print("======================================")
print("   BIENVENUE DANS MiniStock !")
print("   Gestion de stock – Papeterie Express")
print("   Tunis – Mars 2026")
print("======================================\n")

nom_boutique = "Papeterie Bejaoui"
prix_cahier_ht = 3.50           # en dinars
quantite_initiale_cahiers = 45
taux_tva = 0.19

prix_cahier_ttc = prix_cahier_ht * (1 + taux_tva)
valeur_stock_cahiers = prix_cahier_ht * quantite_initiale_cahiers

print(f"Bienvenue à la {nom_boutique}")
print(f"Prix d'un cahier HT       : {prix_cahier_ht:.2f} TND")
print(f"Prix d'un cahier TTC      : {prix_cahier_ttc:.2f} TND")
print(f"Stock initial cahiers     : {quantite_initiale_cahiers} unités")
print(f"Valeur du stock cahiers   : {valeur_stock_cahiers:.2f} TND\n")

print("Projet initialisé.")
print("Ce script sera enrichi à chaque étape de la formation.")
```

**3. Commandes à exécuter**

```bash
cd projet_fil_rouge
python -m venv .venv
# Activer l'environnement virtuel :
# Linux/macOS :    source .venv/bin/activate
# Windows :        .venv\Scripts\activate

pip install -r requirements.txt
python ministock_v0.py
```

**Défi facultatif**

- un deuxième article (exemple : stylo bleu à 1.20 TND, 120 unités)
- son prix TTC
- sa valeur de stock
- la valeur totale du stock pour les deux articles

Exécutez à nouveau le script après modification.
