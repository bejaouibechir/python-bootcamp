# 1️⃣ Présentation des flux conditionnels

## 1.1 Objectif des structures conditionnelles

Un programme professionnel ne se contente pas d'exécuter des instructions séquentiellement.
Il doit :

- Prendre des décisions

- Contrôler l'exécution

- Gérer des cas métier réels

- Sécuriser des scénarios imprévus

Les flux conditionnels permettent d'orienter l'exécution selon des règles logiques.

---

## 1.2 Logique fondamentale

Un flux conditionnel repose sur :

- Une expression logique

- Une évaluation booléenne

- Une bifurcation d'exécution

Schéma conceptuel :

```
Début
→ Évaluation d'une condition
→ Exécution bloc A si vrai
→ Exécution bloc B si faux
```

---

## 1.3 Le mot-clé if

Structure de base :

```
if condition:
    bloc_exécuté_si_vrai
```

Exemple minimal :

```python
"""
La condition retourne True ou False.
Le bloc indenté s'exécute uniquement si True.
L'indentation définit la portée du bloc.
"""

age = 20

if age >= 18:
    print("Majeur")
```

---

## 1.4 Structure if / else

Permet de définir un comportement alternatif.

```python
"""
Une seule branche s'exécute.
L'évaluation est exclusive.
"""

age = 16

if age >= 18:
    print("Majeur")
else:
    print("Mineur")
```

---

## 1.5 Structure if / elif / else

Permet de gérer plusieurs cas mutuellement exclusifs.

```python
"""
Les conditions sont évaluées dans l'ordre.
Dès qu'une condition est vraie, les suivantes ne sont plus évaluées.
else est facultatif mais recommandé pour couvrir les cas restants.
"""

note = 14

if note < 10:
    print("Échec")
elif note < 12:
    print("Passable")
elif note < 14:
    print("Assez bien")
elif note < 16:
    print("Bien")
else:
    print("Très bien")
```

---

## 1.6 Expression conditionnelle (opérateur ternaire)

Forme compacte :

```
valeur_si_vrai if condition else valeur_si_faux
```

```python
"""
Forme concise pour affectation simple.
À éviter pour les logiques complexes ou imbriquées.
"""

a = 5
b = 10

resultat = "A plus grand" if a > b else "B plus grand ou égal"
print(resultat)
```

Utilisation adaptée :

- Affectation simple

- Retour de fonction

- Expressions concises

À éviter :

- Imbrications multiples

- Logique complexe

## 1.7 Opérateurs de comparaison

```python
"""
Les six opérateurs de comparaison standard.
Chacun retourne True ou False.
"""

temperature = 35

print(temperature == 35)    # égalité
print(temperature != 30)    # différence
print(temperature > 30)     # supérieur
print(temperature >= 35)    # supérieur ou égal
print(temperature < 40)     # inférieur
print(temperature <= 35)    # inférieur ou égal

if temperature > 30:
    print("Alerte chaleur")
```

## 1.8 Opérateurs logiques

Permettent de combiner plusieurs conditions.

```python
"""
and → toutes les conditions doivent être vraies
or  → au moins une condition doit être vraie
not → inversion logique
"""

age    = 25
permis = True

if age >= 18 and permis:
    print("Autorisé à conduire")

if age < 18 or not permis:
    print("Non autorisé")
```

## 1.11 Court-circuit logique

```python
"""
Avec and : si la première condition est False,
la seconde n'est pas évaluée.
Avec or  : si la première condition est True,
la seconde n'est pas évaluée.
Utile pour éviter des erreurs d'exécution.
"""

x = 0

if x != 0 and 10 / x > 1:
    print("Valide")
else:
    print("Division évitée grâce au court-circuit")
```

## 1.12 match / case — Python 3.10+

```python
"""
match/case est la solution moderne pour remplacer
les longues chaînes if/elif sur une même variable.
Plus lisible et plus expressif.
"""

commande = "quitter"

match commande:
    case "démarrer":
        print("Application démarrée")
    case "arrêter":
        print("Application arrêtée")
    case "quitter":
        print("Au revoir")
    case _:
        print("Commande inconnue")
```

### Avec conditions — guards

```python
"""
Les guards permettent d'ajouter une condition
à l'intérieur d'un case.
"""

score = 85

match score:
    case s if s >= 90:
        print("Excellent")
    case s if s >= 70:
        print("Bien")
    case s if s >= 50:
        print("Passable")
    case _:
        print("Insuffisant")
```

## 1.14 Pièges fréquents

### Confusion entre = et ==

```python
"""
= est une affectation.
== est une comparaison.
Utiliser = dans un if provoque une SyntaxError.
"""

age = 18

# Incorrect → SyntaxError
# if age = 18:

# Correct
if age == 18:
    print("Exactement 18 ans")
```

---

### Confusion entre & et and

```python
"""
and est un opérateur logique — court-circuit.
&   est un opérateur bit à bit — pas de court-circuit.
Utiliser and dans les conditions logiques.
"""

a = 5

# Correct
if 0 < a < 10:
    print("Dans l'intervalle")

# Risqué
if (0 < a) & (a < 10):
    print("Fonctionne mais déconseillé")
```

---

### Ordre incorrect des conditions

```python
"""
Une condition large placée en premier
rend les conditions suivantes inaccessibles.
"""

age = 25

# Incorrect — la seconde condition n'est jamais atteinte
if age >= 0:
    print("Age valide")
elif age >= 18:
    print("Majeur")    # jamais atteint

# Correct
if age >= 18:
    print("Majeur")
elif age >= 0:
    print("Mineur")
```

---

### Piège avec or

```python
"""
"manager" seul est toujours évalué comme True.
Il ne compare pas role à "manager".
"""

role = "user"

# Incorrect — toujours True
if role == "admin" or "manager":
    print("Toujours exécuté")

# Correct
if role == "admin" or role == "manager":
    print("Condition correcte")

# Pythonique
if role in ["admin", "manager"]:
    print("Condition optimisée")
```

# Synthèse

- `if / elif / else` couvre les cas mutuellement exclusifs

- L'ordre des `elif` est critique — du plus restrictif au plus large

- L'évaluation implicite évite les comparaisons redondantes

- Le chaînage `18 <= age < 65` est plus lisible qu'un double `and`

- Le court-circuit `and` / `or` protège contre les erreurs d'exécution

- `match/case` (Python 3.10+) remplace avantageusement les longues chaînes `if/elif`

- Ne jamais écrire `role == "admin" or "manager"` — utiliser `in`

- Toujours couvrir les cas limites : `None`, `0`, `""`, valeurs négatives

# 1) Différence entre and et &

## Énoncé

Pourquoi utiliser and au lieu de & dans une condition logique ?

## Solution

```python
"""
Explication :
and est un opérateur logique avec court-circuit.
& est un opérateur bit à bit sans court-circuit.
Les deux ne sont pas équivalents.
"""

a = 5
b = 3

if a > 0 and b > 0:
    print("Condition logique valide")

if (a > 0) & (b > 0):
    print("Condition bit à bit exécutée")

print("Résultat and :", a > 0 and b > 0)
print("Résultat &   :", (a > 0) & (b > 0))
```

Explication :

# 20) Refactorisation avancée

## Énoncé

Quand remplacer un long if/elif par un dictionnaire ?

## Solution

```python
"""
Explication :
Un dictionnaire de fonctions remplace avantageusement
une longue chaîne if/elif sur une même variable.
Plus extensible et plus lisible.
"""

def addition(a, b):
    return a + b

def soustraction(a, b):
    return a - b

def multiplication(a, b):
    return a * b

operations = {
    "+": addition,
    "-": soustraction,
    "*": multiplication
}

op = "+"
a  = 5
b  = 3

if op in operations:
    print(f"{a} {op} {b} = {operations[op](a, b)}")
else:
    print("Opération invalide")
```
