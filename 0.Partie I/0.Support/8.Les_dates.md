# 1️⃣ Introduction

La gestion des dates est une compétence fondamentale :

- Horodatage des événements

- Calcul de délais et d'échéances

- Formatage pour affichage ou export

- Comparaison et tri chronologique

Python propose le module **datetime** comme outil central.

# 2️⃣ Le module datetime

## Structure du module

```python
"""
Le module datetime contient plusieurs classes :
- date      → date seule (année, mois, jour)
- time      → heure seule (heure, minute, seconde)
- datetime  → date + heure combinées
- timedelta → durée / intervalle
- timezone  → gestion des fuseaux horaires
"""

from datetime import date, time, datetime, timedelta, timezone
```

weekday() retourne un entier :
0 = Lundi, 1 = Mardi, ..., 6 = Dimanche

# 9️⃣ Formatage — strftime

strftime convertit une date en chaîne selon un format.

```python
"""
Formatage d'une date en chaîne lisible.
"""

from datetime import datetime

maintenant = datetime.now()

print(maintenant.strftime("%d/%m/%Y"))
print(maintenant.strftime("%d/%m/%Y %H:%M:%S"))
print(maintenant.strftime("%A %d %B %Y"))
```

Codes fréquents :

| Code | Signification    |
| ---- | ---------------- |
| %Y   | Année 4 chiffres |
| %m   | Mois 2 chiffres  |
| %d   | Jour 2 chiffres  |
| %H   | Heure (24h)      |
| %M   | Minutes          |
| %S   | Secondes         |
| %A   | Nom du jour      |
| %B   | Nom du mois      |

# 🔟 Parsing — strptime

strptime convertit une chaîne en datetime.

```python
"""
Conversion d'une chaîne en objet datetime.
Le format doit correspondre exactement à la chaîne.
"""

from datetime import datetime

chaine = "15/06/2024"
dt = datetime.strptime(chaine, "%d/%m/%Y")

print(dt)
print(type(dt))
```

### Gestion des erreurs de parsing

```python
"""
Un format incorrect provoque une ValueError.
Toujours protéger le parsing en production.
"""

from datetime import datetime

def parser_date(chaine, format):
    try:
        return datetime.strptime(chaine, format)
    except ValueError as e:
        print("Erreur de parsing :", e)
        return None

print(parser_date("2024-06-15", "%d/%m/%Y"))
print(parser_date("15/06/2024", "%d/%m/%Y"))
```

# 1️⃣2️⃣ Fuseau horaire — timezone

```python
"""
Utiliser timezone pour les dates conscientes du fuseau horaire.
Depuis Python 3.12, datetime.utcnow() est déprécié.
Préférer datetime.now(timezone.utc).
"""

from datetime import datetime, timezone, timedelta

utc_now = datetime.now(timezone.utc)
print("UTC    :", utc_now)

paris = timezone(timedelta(hours=1))
paris_now = datetime.now(paris)
print("Paris  :", paris_now)
```

### Point important

```python
"""
Une date sans fuseau horaire est dite "naive".
Une date avec fuseau est dite "aware".
Ne jamais comparer une date naive avec une date aware.
"""

from datetime import datetime, timezone

naive = datetime.now()
aware = datetime.now(timezone.utc)

try:
    print(naive < aware)
except TypeError as e:
    print("Erreur :", e)
```

# Synthèse

| Classe    | Usage                          |
| --------- | ------------------------------ |
| date      | Date seule (année, mois, jour) |
| time      | Heure seule                    |
| datetime  | Date + heure combinées         |
| timedelta | Durée / calcul d'intervalle    |
| timezone  | Gestion des fuseaux horaires   |

- `strftime` convertit une date en chaîne

- `strptime` convertit une chaîne en date — format doit correspondre exactement

- `weekday()` retourne 0 (Lundi) à 6 (Dimanche)

- `isoformat()` est le standard pour les APIs et échanges de données

- Depuis Python 3.12, `utcnow()` est déprécié — utiliser `datetime.now(timezone.utc)`

- Ne jamais comparer une date naive avec une date aware

## Énoncé

## Solution

```python
"""
Explication :
Comparer mois et jour pour calculer l'âge exact.
La division par 365 est incorrecte pour les années bissextiles.
"""

from datetime import date

def calculer_age(naissance):
    aujourd_hui = date.today()
    age = aujourd_hui.year - naissance.year

    if (aujourd_hui.month, aujourd_hui.day) < (naissance.month, naissance.day):
        age -= 1

    return age

print(calculer_age(date(1990, 6, 15)))
```

# 12) Comment calculer le nombre de jours ouvrables ?

## Énoncé

Itérer en excluant samedi et dimanche.

## Solution

```python
"""
Explication :
weekday() retourne 0-4 pour lundi-vendredi.
On itère et on compte uniquement les jours < 5.
"""

from datetime import date, timedelta

def jours_ouvrables(debut, fin):
    compte  = 0
    courant = debut
    while courant <= fin:
        if courant.weekday() < 5:
            compte += 1
        courant += timedelta(days=1)
    return compte

debut = date(2024, 1, 1)
fin   = date(2024, 1, 31)

print(jours_ouvrables(debut, fin))
```
