# 2. Création du fichier ministock_v2.py

Créer le fichier **ministock_v2.py**

```python
# MiniStock – Papeterie Express
# Version 2 – Flux conditionnels

print("======================================")
print("   MiniStock – Papeterie Express")
print("           Version 2")
print("======================================\n")

# Configuration
SEUIL_ALERTE = 5

# Données du stock
stock = {
    "A001": 18,
    "B012": 4,
    "C005": 32,
    "D008": 0,
    "E015": 12
}

produits = [
    {"ref": "A001", "nom": "Cahier 96 pages", "prix_ht": 3.50},
    {"ref": "B012", "nom": "Stylo bleu", "prix_ht": 1.20},
    {"ref": "C005", "nom": "Ramette A4", "prix_ht": 4.99},
    {"ref": "D008", "nom": "Marqueur noir", "prix_ht": 2.80},
    {"ref": "E015", "nom": "Gomme blanche", "prix_ht": 0.80}
]

print("État du stock avec alertes :\n")

for produit in produits:

    ref = produit["ref"]
    qte = stock.get(ref, 0)

    if qte == 0:
        statut = "RUPTURE"
    elif qte <= SEUIL_ALERTE:
        statut = "STOCK BAS"
    else:
        statut = "OK"

    print(f"{ref} - {produit['nom']} : {qte} unités ({statut})")

print("\nSimulation d'une vente :")

ref_demande = "B012"
quantite_demande = 3

if ref_demande not in stock:
    print("Référence inconnue")

elif stock[ref_demande] < quantite_demande:
    print("Stock insuffisant")

else:
    stock[ref_demande] -= quantite_demande
    print("Vente acceptée")
    print("Nouveau stock :", stock[ref_demande])
```

# Défi

Améliorer le programme pour rendre la vente **interactive**.

Le programme doit :

1. demander à l’utilisateur la **référence du produit**

2. demander la **quantité à vendre**

3. vérifier que le stock est suffisant

4. calculer le **montant de la vente**

Règles :

- si le total HT dépasse **50 TND**, appliquer **5 % de remise**

- calculer ensuite le **prix TTC** avec une TVA de **19 %**

---

# Solution du défi

Modifier le fichier **ministock_v2.py**

```python
# TVA
TVA = 0.19

# Saisie utilisateur
ref_demande = input("Référence du produit : ")
quantite_demande = int(input("Quantité à vendre : "))

# Recherche du produit
produit_trouve = None

for p in produits:
    if p["ref"] == ref_demande:
        produit_trouve = p
        break

if produit_trouve is None:
    print("Référence inconnue")

elif stock.get(ref_demande, 0) < quantite_demande:
    print("Stock insuffisant")

else:

    prix = produit_trouve["prix_ht"]

    total_ht = prix * quantite_demande

    if total_ht > 50:
        remise = total_ht * 0.05
        total_ht -= remise
        print("Remise appliquée :", round(remise,2),"TND")

    total_ttc = total_ht * (1 + TVA)

    stock[ref_demande] -= quantite_demande

    print("\nVente acceptée")
    print("Montant HT :", round(total_ht,2),"TND")
    print("Montant TTC :", round(total_ttc,2),"TND")
    print("Stock restant :", stock[ref_demande])
```
