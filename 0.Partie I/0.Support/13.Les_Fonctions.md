# 1️⃣ Pourquoi les fonctions ?

Une fonction est une unité logique de traitement permettant :

- Structurer un programme

- Réutiliser du code

- Isoler la logique métier

- Tester indépendamment des blocs fonctionnels

- Réduire la complexité globale

Dans un contexte réel (ex : système RH, gestion de commandes, analyse de données), chaque action métier doit être encapsulée dans une fonction dédiée.

# 3️⃣ Fonction avec valeur de retour

```python
"""
return renvoie une valeur exploitable par l'appelant.
print affiche uniquement — la valeur ne peut pas être réutilisée.
"""

def carre(x):
    return x * x

resultat = carre(5)
print(resultat)

# Différence return vs print
def addition_print(a, b):
    print(a + b)       # affiche mais ne retourne rien

def addition_return(a, b):
    return a + b       # valeur réutilisable

r = addition_return(3, 4)
print("Résultat réutilisable :", r * 2)
```

# 4️⃣ Paramètres et passage d'arguments

## 4.1 Passage par objet

Python transmet une référence vers l'objet.

### Cas objet immuable

```python
"""
Les entiers sont immuables.
Toute modification crée un nouvel objet local.
La variable externe n'est pas affectée.
"""

def incrementer(n):
    n += 1
    print("Dans fonction :", n)

a = 10
incrementer(a)
print("Après appel    :", a)    # inchangé
```

---

### Cas objet mutable

```python
"""
Les listes sont mutables.
La modification impacte l'objet d'origine.
"""

def ajouter_element(liste):
    liste.append(100)

ma_liste = [1, 2, 3]
ajouter_element(ma_liste)
print(ma_liste)    # [1, 2, 3, 100]
```

## 4.2 Paramètres par défaut

```python
"""
Les paramètres avec valeur par défaut sont optionnels à l'appel.
Ils doivent toujours être placés après les paramètres obligatoires.
"""

def saluer(nom, message="Bonjour"):
    print(f"{message}, {nom}")

saluer("Alice")               # Bonjour, Alice
saluer("Bob", "Bonsoir")      # Bonsoir, Bob
```

### ⚠️ Piège classique : valeur mutable par défaut

```python
"""
Les valeurs par défaut sont évaluées une seule fois à la définition.
Une liste par défaut est partagée entre tous les appels.
"""

def ajouter(element, liste=[]):
    liste.append(element)
    return liste

print(ajouter(1))    # [1]
print(ajouter(2))    # [1, 2]  ← effet inattendu
```

Solution correcte :

```python
"""
Utiliser None et créer une nouvelle liste dynamiquement.
"""

def ajouter(element, liste=None):
    if liste is None:
        liste = []
    liste.append(element)
    return liste

print(ajouter(1))    # [1]
print(ajouter(2))    # [2]
```

# 5️⃣ Nombre variable d'arguments — *args et **kwargs

## 5.1 *args — arguments positionnels variables

```python
"""
*args capture tous les arguments positionnels supplémentaires.
Le résultat est un TUPLE — pas une liste.
Le nom args est une convention — le * est obligatoire.
"""

def somme(*args):
    print("Type de args :", type(args))    # <class 'tuple'>
    print("Contenu      :", args)
    return sum(args)

print(somme(1, 2, 3))          # 6
print(somme(10, 20, 30, 40))   # 100
print(somme())                 # 0 — zéro argument accepté
```

---

## 5.2 **kwargs — arguments nommés variables

```python
"""
**kwargs capture tous les arguments nommés supplémentaires.
Le résultat est un DICT — clés = noms des arguments.
Le nom kwargs est une convention — le ** est obligatoire.
"""

def afficher_infos(**kwargs):
    print("Type de kwargs :", type(kwargs))    # <class 'dict'>
    print("Contenu        :", kwargs)
    for cle, valeur in kwargs.items():
        print(f"  {cle} : {valeur}")

afficher_infos(nom="Alice", age=30, ville="Paris")
afficher_infos(produit="Laptop", prix=999.99)
```

---

## 5.3 Ordre obligatoire des paramètres

```python
"""
L'ordre des paramètres est strict en Python :
1. Paramètres positionnels obligatoires
2. Paramètres avec valeur par défaut
3. *args
4. Paramètres keyword-only (après *)
5. **kwargs
"""

def fonction_complete(a, b=10, *args, option=False, **kwargs):
    print(f"a       = {a}")
    print(f"b       = {b}")
    print(f"args    = {args}")
    print(f"option  = {option}")
    print(f"kwargs  = {kwargs}")

fonction_complete(1, 2, 3, 4, option=True, x=99, y=100)
```

Sortie :

```
a       = 1
b       = 2
args    = (3, 4)
option  = True
kwargs  = {'x': 99, 'y': 100}
```

## 5.5 Déballage à l'appel — * et **

```python
"""
* déballe une liste/tuple en arguments positionnels.
** déballe un dictionnaire en arguments nommés.
"""

def addition(a, b, c):
    return a + b + c

valeurs = [1, 2, 3]
print(addition(*valeurs))    # équivalent à addition(1, 2, 3)

params = {"a": 10, "b": 20, "c": 30}
print(addition(**params))    # équivalent à addition(a=10, b=20, c=30)
```

# 8️⃣ Fonctions imbriquées et closures

```python
"""
Une closure capture les variables de son environnement.
La fonction interne garde accès aux variables de externe
même après que externe ait terminé.
"""

def multiplicateur(n):
    def interne(x):
        return x * n    # n est capturé depuis externe
    return interne

fois3 = multiplicateur(3)
fois5 = multiplicateur(5)

print(fois3(10))    # 30
print(fois5(10))    # 50
```

# 1️⃣1️⃣ Docstrings — format professionnel

```python
"""
Format Google — standard le plus répandu en entreprise.
"""

def calculer_remise(prix: float, taux: float) -> float:
    """
    Calcule le prix après application d'une remise.

    Args:
        prix  : Prix initial hors remise.
        taux  : Taux de remise entre 0 et 1 (ex: 0.10 pour 10%).

    Returns:
        Prix après remise.

    Raises:
        ValueError: Si le taux est hors de l'intervalle [0, 1].

    Example:
        >>> calculer_remise(100, 0.10)
        90.0
    """
    if not 0 <= taux <= 1:
        raise ValueError(f"Taux invalide : {taux}")
    return prix * (1 - taux)

print(calculer_remise(100, 0.10))
```

# 1️⃣2️⃣ Récursivité

```python
"""
Une fonction récursive s'appelle elle-même.
Deux éléments obligatoires :
- Condition d'arrêt (cas de base)
- Appel récursif qui converge vers le cas de base
Sans condition d'arrêt → RecursionError.
"""

def factoriel(n: int) -> int:
    """
    Calcule n! récursivement.
    factoriel(5) = 5 * 4 * 3 * 2 * 1 = 120
    """
    if n == 0:
        return 1          # cas de base
    return n * factoriel(n - 1)    # appel récursif

print(factoriel(5))    # 120
print(factoriel(0))    # 1
```

### Limite de récursion

# 1️⃣3️⃣ Générateurs et yield

```python
"""
yield produit une valeur sans terminer la fonction.
Le générateur reprend à la ligne suivante au prochain appel.
Économie mémoire : les valeurs sont produites à la demande.
"""

def compteur(maximum: int):
    n = 0
    while n < maximum:
        yield n
        n += 1

for valeur in compteur(5):
    print(valeur)

# Un générateur ne peut être parcouru qu'une fois
g = (x for x in range(3))
print(list(g))    # [0, 1, 2]
print(list(g))    # []  ← épuisé
```

# Synthèse

- Une fonction encapsule une logique réutilisable et testable

- `return` renvoie une valeur — sans `return` la fonction retourne `None`

- Python transmet une référence — les mutables sont modifiés en place

- `*args` capture un **tuple** d'arguments positionnels variables

- `**kwargs` capture un **dict** d'arguments nommés variables

- Ordre obligatoire : `pos`, `défaut`, `*args`, `keyword-only`, `**kwargs`

- Ne jamais utiliser une valeur mutable comme paramètre par défaut

- `global` est à éviter — préférer le retour de valeur

- `nonlocal` modifie une variable de la fonction englobante

- Les closures capturent les variables de leur environnement

- Les générateurs produisent les valeurs à la demande — économie mémoire

- Documenter avec le format Google et annoter les types

# 14) yield vs return

## Énoncé

Quelle différence comportementale ?

## Solution

```python
"""
Explication :
return termine la fonction et renvoie une valeur.
yield produit une valeur et suspend — reprend au prochain appel.
Les générateurs économisent la mémoire.
"""

def avec_return(n):
    return list(range(n))    # crée toute la liste en mémoire

def avec_yield(n):
    i = 0
    while i < n:
        yield i              # produit à la demande
        i += 1

for x in avec_yield(5):
    print(x)
```

## Solution

```python
"""
Explication :
Un générateur ne peut être parcouru qu'une seule fois.
Une fois épuisé, il ne produit plus rien.
Pour réitérer, recréer le générateur.
"""

g = (x for x in range(3))

print(list(g))    # [0, 1, 2]
print(list(g))    # []  ← épuisé

# Recréer si nécessaire
g = (x for x in range(3))
print(list(g))    # [0, 1, 2]
```

# 16) Lambda limitée

## Énoncé

Pourquoi lambda ne peut contenir plusieurs instructions ?

## Solution

```python
"""
Explication :
lambda accepte uniquement une expression — pas des instructions.
Pour une logique multi-lignes, utiliser def.
"""

# Lambda simple
max2 = lambda a, b: a if a > b else b
print(max2(3, 8))

# Cas complexe → préférer def
def max_propre(a, b):
    if a > b:
        return a
    return b

print(max_propre(3, 8))
```

# 17) Fonction récursive — condition d'arrêt

## Énoncé

Que se passe-t-il sans condition d'arrêt ?

## Solution

```python
"""
Explication :
Sans condition d'arrêt → RecursionError.
Python limite la profondeur à 1000 par défaut.
La condition d'arrêt est le cas de base.
"""

import sys
print("Limite récursion :", sys.getrecursionlimit())

def factoriel(n: int) -> int:
    if n == 0:           # cas de base — condition d'arrêt
        return 1
    return n * factoriel(n - 1)

print(factoriel(5))    # 120
```

# 18) Paramètres keyword-only

## Énoncé

Pourquoi forcer l'usage par nom ?

## Solution

```python
"""
Explication :
Tout paramètre après * doit être passé par nom.
Améliore la lisibilité et évite les erreurs de position.
"""

def configurer(adresse: str, *, port: int = 80, ssl: bool = False) -> None:
    print(f"{adresse} — port={port} — ssl={ssl}")

configurer("localhost", port=8080, ssl=True)

try:
    configurer("localhost", 8080)    # TypeError
except TypeError as e:
    print("Erreur :", e)
```

# 19) Shadowing d'une variable globale

## Énoncé

Pourquoi cette variable globale n'est pas modifiée ?

## Solution

```python
"""
Explication :
Une affectation dans une fonction crée une variable locale.
Elle masque (shadow) la variable globale sans la modifier.
Utiliser global pour modifier explicitement.
"""

x = 10

def f():
    x = 5           # variable locale — masque la globale
    print("Locale :", x)

f()
print("Globale :", x)    # 10 — inchangée
```

# 20) functools.partial — spécialisation

## Énoncé

Comment préconfigurer une fonction ?

## Solution

```python
"""
Explication :
partial crée une nouvelle fonction avec certains arguments
déjà fixés.
Utile pour spécialiser des fonctions génériques.
"""

from functools import partial

def multiplier(a: int, b: int) -> int:
    return a * b

fois2  = partial(multiplier, 2)
fois10 = partial(multiplier, 10)

print(fois2(5))     # 10
print(fois10(5))    # 50

# Cas métier : formater des prix
def formater(valeur: float, symbole: str, decimales: int) -> str:
    return f"{valeur:.{decimales}f} {symbole}"

formater_euro = partial(formater, symbole="€", decimales=2)
print(formater_euro(19.9876))    # 19.99 €
```
