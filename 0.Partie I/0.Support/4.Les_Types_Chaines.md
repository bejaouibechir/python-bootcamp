# 1️⃣ Nature des chaînes

Une chaîne :

- est une séquence ordonnée de caractères

- est immuable

- est indexable

- est itérable

- supporte slicing et méthodes dédiées

# 2️⃣ Création d'une chaîne

```python
"""
Une chaîne peut être délimitée par :
- guillemets simples
- guillemets doubles
- triples guillemets pour multi-ligne
"""

s1 = "Python"
s2 = 'Python'
s3 = """Ligne 1
Ligne 2"""
```

# 3️⃣ Caractères d'échappement *(ajout)*

```python
"""
Les séquences d'échappement permettent d'insérer
des caractères spéciaux dans une chaîne.
"""

print("Ligne 1\nLigne 2")       # saut de ligne
print("Col1\tCol2")             # tabulation
print("Il dit : \"Bonjour\"")   # guillemet dans chaîne
print("C:\\Users\\alice")       # antislash littéral
```

Sortie :

```
Ligne 1
Ligne 2
Col1    Col2
Il dit : "Bonjour"
C:\Users\alice
```

# 4️⃣ Raw strings — r""

```python
"""
Une raw string désactive les séquences d'échappement.
Indispensable pour les chemins Windows et les expressions régulières.
"""

chemin = r"C:\Users\alice\Documents"
print(chemin)

pattern = r"\d+\.\d+"
print(pattern)
```

### Point important

Sans le préfixe `r`, `\U`, `\a`, `\d` seraient interprétés comme des échappements.

# 5️⃣ Immutabilité — démonstration fondamentale

```python
"""
Les chaînes sont immuables.
On ne peut pas modifier un caractère en place.
Toute modification crée un nouvel objet.
"""

mot = "Hello"

print(id(mot))

mot = mot + " world"

print(id(mot))  # adresse différente
```

Tentative interdite :

```python
"""
Modification directe impossible.
"""

mot = "Hello"

try:
    mot[0] = "Y"
except TypeError as e:
    print("Erreur :", e)
```

# 2️⃣2️⃣ Cas métier : Nettoyage d'un nom utilisateur

Objectif :

- supprimer espaces inutiles

- supprimer accents

- passer en minuscules

- générer identifiant propre

```python
"""
Nettoyage robuste pour identifiant utilisateur.
"""

import unicodedata

def nettoyer_nom(nom):
    nom = nom.strip()
    nom = unicodedata.normalize("NFKD", nom)
    nom = "".join(c for c in nom if not unicodedata.combining(c))
    nom = nom.lower()
    nom = nom.replace(" ", "")
    return nom

print(nettoyer_nom("  BéChir Bejaoui  "))
```

# Synthèse opérationnelle

Une chaîne :

- est immuable

- supporte les caractères d'échappement (`\n`, `\t`, `\\`)

- utilise `r""` pour désactiver les échappements (chemins, regex)

- supporte slicing puissant

- possède de nombreuses méthodes intégrées

- doit être manipulée efficacement (join > concaténation répétée)

- est centrale dans le traitement de données, parsing, validation, logs

# Tableau récapitulatif des méthodes *(ajout)*

| Méthode        | Rôle                       | Exemple                                   |
| -------------- | -------------------------- | ----------------------------------------- |
| `lower()`      | Minuscules                 | `"ABC".lower()` → `"abc"`                 |
| `upper()`      | Majuscules                 | `"abc".upper()` → `"ABC"`                 |
| `title()`      | Première lettre maj        | `"hello world".title()` → `"Hello World"` |
| `strip()`      | Supprime espaces début/fin | `" abc ".strip()` → `"abc"`               |
| `lstrip()`     | Supprime espaces début     | `" abc ".lstrip()` → `"abc "`             |
| `rstrip()`     | Supprime espaces fin       | `" abc ".rstrip()` → `" abc"`             |
| `replace(a,b)` | Remplace occurrences       | `"ab".replace("a","x")` → `"xb"`          |
| `split()`      | Découpe en liste           | `"a b".split()` → `["a","b"]`             |
| `join()`       | Assemble une liste         | `"-".join(["a","b"])` → `"a-b"`           |
| `find()`       | Cherche, retourne -1       | `"abc".find("b")` → `1`                   |
| `index()`      | Cherche, lève exception    | `"abc".index("b")` → `1`                  |
| `count()`      | Compte occurrences         | `"abab".count("a")` → `2`                 |
| `startswith()` | Teste début                | `"abc".startswith("a")` → `True`          |
| `endswith()`   | Teste fin                  | `"abc".endswith("c")` → `True`            |
| `isdigit()`    | Que des chiffres ?         | `"123".isdigit()` → `True`                |
| `isalpha()`    | Que des lettres ?          | `"abc".isalpha()` → `True`                |
| `casefold()`   | Minuscules Unicode         | `"ß".casefold()` → `"ss"`                 |

```python
Explication
```

# 20) Cas métier complet : génération d'identifiant

## Énoncé

Transformer un nom complet en identifiant système sécurisé.

## Solution

```python
"""
Explication
Enchaînement complet :
1. strip
2. normalisation Unicode
3. suppression accents
4. lower
5. remplacement espaces
6. suppression caractères non alphanumériques
"""

import unicodedata
import re

def generer_identifiant(nom):
    nom = nom.strip()
    nom = unicodedata.normalize("NFKD", nom)
    nom = "".join(c for c in nom if not unicodedata.combining(c))
    nom = nom.lower()
    nom = nom.replace(" ", "_")
    nom = re.sub(r"[^a-z0-9_]", "", nom)
    return nom

print(generer_identifiant("  BéChir Bejaoui  "))
```
