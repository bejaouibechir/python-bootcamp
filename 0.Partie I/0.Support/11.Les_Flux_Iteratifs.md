# 1️⃣ Présentation des flux itératifs

Les flux itératifs permettent d'exécuter un bloc d'instructions plusieurs fois.

Ils répondent à trois besoins fondamentaux :

- Répéter une action un nombre déterminé de fois

- Répéter une action tant qu'une condition reste vraie

- Parcourir une structure de données

Python propose deux structures principales :

- while

- for

---

# 2️⃣ La boucle while

## 2.1 Principe général

La boucle while exécute un bloc tant qu'une condition booléenne est vraie.

Structure :

```python
while condition:
    bloc
```

La condition est évaluée avant chaque itération.

---

## 2.2 Fonctionnement détaillé

```python
"""
Objectif :
Afficher les nombres de 1 à 5.
Montrer le mécanisme complet : initialisation, condition, mise à jour.
"""

i = 1              # Initialisation du compteur

while i <= 5:      # Condition testée avant chaque itération
    print("Valeur actuelle :", i)
    i += 1         # Mise à jour indispensable pour éviter boucle infinie

print("Fin de boucle")
```

Points essentiels :

- Initialisation obligatoire

- Mise à jour obligatoire

- Risque de boucle infinie si oubli

---

## 2.3 Boucle infinie maîtrisée

```python
"""
Boucle infinie contrôlée via break.
Utilisation typique : menus interactifs, serveurs, processus d'attente.
"""

while True:
    reponse = input("Tapez 'stop' pour quitter : ")

    if reponse == "stop":
        print("Arrêt demandé")
        break

print("Programme terminé")
```

---

## 2.4 Validation d'entrée robuste

```python
"""
Objectif :
Demander un âge valide (>= 0).
Répéter tant que la saisie est incorrecte.
Concepts mobilisés : while True, continue, break, gestion d'erreur.
"""

while True:
    try:
        age = int(input("Entrez votre âge : "))

        if age < 0:
            print("Âge invalide")
            continue

        break    # sortie si valide

    except ValueError:
        print("Veuillez entrer un nombre valide")

print("Âge enregistré :", age)
```

# 3️⃣ La boucle for

## 3.1 Principe général

La boucle for parcourt un itérable.

Structure :

```python
for element in iterable:
    bloc
```

---

## 3.2 Parcours d'une liste

```python
"""
Parcours simple d'une collection.
À chaque itération, fruit contient l'élément courant.
"""

fruits = ["pomme", "banane", "fraise"]

for fruit in fruits:
    print("Fruit :", fruit)
```

---

## 3.3 Utilisation de range

range génère une séquence de nombres sans créer une liste en mémoire.

```python
"""
Affichage de 0 à 4.
range(stop)       → 0 à stop-1
range(start,stop) → start à stop-1
range(start,stop,step) → avec pas
"""

for i in range(5):
    print(i)

for i in range(2, 6):
    print(i)

for i in range(0, 10, 2):
    print(i)

# Compte à rebours
for i in range(5, 0, -1):
    print(i)
```

---

## 3.4 enumerate

Obtenir index + valeur simultanément.

```python
"""
enumerate évite la gestion manuelle d'un compteur.
Le paramètre start définit la valeur de départ de l'index.
"""

noms = ["Alice", "Bob", "Charlie"]

for index, nom in enumerate(noms, start=1):
    print(index, "-", nom)
```

---

## 3.5 zip — itération parallèle

Parcourir plusieurs itérables simultanément.

```python
"""
zip associe les éléments de même position.
S'arrête au plus court des itérables.
"""

noms = ["Alice", "Bob", "Charlie"]
ages = [25, 30, 22]

for nom, age in zip(noms, ages):
    print(f"{nom} a {age} ans")
```

## 3.6 Parcours d'un dictionnaire

```python
"""
Parcours clé-valeur avec items().
for d parcourt uniquement les clés.
for d.items() fournit clé + valeur.
"""

utilisateur = {
    "nom"  : "Alice",
    "age"  : 30,
    "ville": "Paris"
}

# Clés uniquement
for cle in utilisateur:
    print("Clé :", cle)

# Clés et valeurs
for cle, valeur in utilisateur.items():
    print(cle, ":", valeur)
```

# 6️⃣ any() et all()

Alternatives concises aux boucles de vérification.

```python
"""
any() retourne True si au moins un élément est vrai.
all() retourne True si tous les éléments sont vrais.
Plus expressifs qu'une boucle for avec drapeau.
"""

notes  = [12, 15, 8, 17]
scores = [11, 13, 14]

# Au moins une note insuffisante ?
if any(n < 10 for n in notes):
    print("Au moins une note insuffisante")

# Tous les scores valides ?
if all(s >= 10 for s in scores):
    print("Tous les scores sont valides")
```

# Synthèse

- `while` répète tant qu'une condition est vraie — nombre d'itérations inconnu

- `for` parcourt un itérable — nombre d'itérations déterminé

- `break` interrompt la boucle courante uniquement

- `continue` passe à l'itération suivante

- `else` s'exécute uniquement si la boucle se termine sans `break`

- `enumerate` fournit index + valeur sans compteur manuel

- `zip` parcourt plusieurs itérables en parallèle

- `any()` et `all()` remplacent avantageusement les boucles de vérification

- Ne jamais modifier une liste pendant son parcours — utiliser `[:]`

- Les compréhensions sont la forme idiomatique de `for` — approfondissement Partie II

# 1) Différence fondamentale entre while et for

## Énoncé

Quand choisir while plutôt que for ?

## Solution

```python
"""
Explication :
for est utilisé quand on connaît l'itérable ou le nombre d'itérations.
while est utilisé quand la répétition dépend d'une condition dynamique.
"""

# Cas déterminé
for i in range(3):
    print("for :", i)

# Cas conditionnel
compteur = 0
while compteur < 3:
    print("while :", compteur)
    compteur += 1
```

# 14) Utilité du else dans recherche

Explication :

for n in liste:

else:

# 17) Utilisation de any()

## Énoncé

Remplacer une boucle de vérification par any.

## Solution

```python
"""
Explication :
any retourne True si au moins un élément satisfait la condition.
Plus concis qu'une boucle with drapeau.
Court-circuit : s'arrête au premier True trouvé.
"""

notes = [12, 15, 8, 17]

# Version boucle
echec = False
for n in notes:
    if n < 10:
        echec = True
        break

# Version any
if any(n < 10 for n in notes):
    print("Au moins une note insuffisante")
```

# 19) Performance : range vs liste

## Énoncé

Pourquoi range est plus léger qu'une liste ?

## Solution

```python
"""
Explication :
range génère les valeurs à la volée sans créer une liste complète.
La mémoire utilisée est identique pour range(10) et range(10_000_000).
"""

import sys

r = range(1_000_000)
l = list(range(1_000_000))

print("Taille range :", sys.getsizeof(r), "octets")
print("Taille liste :", sys.getsizeof(l), "octets")
```

# 20) Refactorisation d'une boucle complexe

## Énoncé

Simplifier un contrôle imbriqué.

## Solution

```python
"""
Explication :
La garde initiale (continue sur condition négative)
évite l'imbrication et améliore la lisibilité.
"""

utilisateurs = [
    {"nom": "Alice", "actif": True},
    {"nom": "Bob",   "actif": False},
    {"nom": "Carol", "actif": True},
]

# Version imbriquée
for user in utilisateurs:
    if user["actif"]:
        print("Traitement :", user["nom"])

# Version avec garde
for user in utilisateurs:
    if not user["actif"]:
        continue

    print("Traitement :", user["nom"])
```
