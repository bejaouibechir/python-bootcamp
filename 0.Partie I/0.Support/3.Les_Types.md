# 1️⃣ Pourquoi comprendre les types ?

Un programme robuste repose sur :

- la maîtrise des types manipulés

- la compréhension des conversions implicites

- l'anticipation des erreurs de typage

- la distinction entre mutabilité et immutabilité

En production, la majorité des bugs proviennent d'une mauvaise gestion des types.

# 3️⃣ Les types numériques

## 3.1 Entiers — int

Caractéristiques :

- précision arbitraire

- pas de limite 32 ou 64 bits

- stockage dynamique

```python
"""
Les entiers en Python ont une précision illimitée.
La seule limite est la mémoire disponible.
"""

x = 10
grand = 10**100

print(type(x))
print(grand)
```

---

## 3.2 Flottants — float

Caractéristiques :

- norme IEEE 754

- précision limitée

- erreurs d'arrondi possibles

```python
"""
Les floats sont représentés en binaire.
Certaines valeurs décimales ne sont pas exactes.
"""

a = 0.1
b = 0.2
print(a + b)
print((a + b) == 0.3)
```

---

## 3.3 Complex — complex

Structure : a + bj

```python
"""
Les nombres complexes possèdent :
- une partie réelle
- une partie imaginaire
Approfondissement en Partie II — Opérateurs avancés.
"""

z = 2 + 3j

print(type(z))
print(z.real)
print(z.imag)
```

# 🔟 Range — séquence paresseuse

Caractéristiques :

- ne stocke pas les éléments en mémoire

- génère les valeurs à la demande

- idéal pour les boucles sur de grandes plages

```python
"""
range est un objet itérable paresseux.
Il ne stocke pas tous les éléments.
La mémoire utilisée est identique pour range(10) et range(10_000_000).

```

# 1️⃣8️⃣ Copie superficielle et copie profonde

Caractéristiques :

- `copy()` duplique la structure externe uniquement

- `deepcopy()` copie récursivement tous les sous-objets

- risque fréquent avec les structures imbriquées

```python
"""
copy() copie la structure externe.
Les sous-objets restent partagés.
"""

import copy

a = [[1, 2], [3, 4]]
b = a.copy()

b[0].append(99)

print("Original :", a)   # affecté
print("Copie    :", b)
```

Correction avec deepcopy :

```python
"""
deepcopy() copie tous les niveaux.
L'original n'est plus affecté.
"""

import copy

a = [[1, 2], [3, 4]]
b = copy.deepcopy(a)

b[0].append(99)

print("Original :", a)   # non affecté
print("Copie    :", b)
```

# 1️⃣9️⃣ Cas réel : bug de mutabilité

```python
"""
Attention aux valeurs par défaut mutables.

    liste.append(element)
    return liste

```

Correction :

```python
def ajouter(element, liste=None):
    if liste is None:
        liste = []
    liste.append(element)
    return liste

print(ajouter(1))
print(ajouter(2))
```

### Exercice 3 — Débogage

Ce code contient 2 erreurs. Les identifier et les corriger.

```python
def historique(valeur, log=[]):
    log.append(valeur)
    return log

print(historique("login"))
print(historique("logout"))   # comportement inattendu
```

<details>
<summary>Solution</summary>

```python
# Erreur 1 : valeur par défaut mutable → partagée entre appels
# Erreur 2 : pas de protection contre l'accumulation involontaire

def historique(valeur, log=None):
    if log is None:
        log = []
    log.append(valeur)
    return log

print(historique("login"))
print(historique("logout"))
```
