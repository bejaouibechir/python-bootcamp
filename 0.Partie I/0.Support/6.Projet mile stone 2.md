**MiniStock – Papeterie Express**  
(après le chapitre 4 – Types collections)

**Objectif**  
Représenter plusieurs articles du stock à l’aide de listes et de dictionnaires.  
Afficher les informations de base du stock de manière structurée.

**1. Structure du projet (inchangée pour cette étape)**

Restez dans le dossier `projet_fil_rouge/` créé à l’étape 0 :

```
projet_fil_rouge/
├── README.md
├── requirements.txt
└── ministock_v0.py          ← conservez-le
    └── ministock_v1.py      ← nouveau fichier à créer
```

**2. Création du fichier ministock_v1.py**

Créez le fichier `ministock_v1.py` et copiez-y le code suivant :

```python
# ministock_v1.py
# MiniStock – Papeterie Express
# Version 1 – Après les types collections

print("======================================")
print("   MiniStock – Papeterie Express")
print("          Version 1")
print("======================================\n")

# Dictionnaire : référence → quantité en stock
stock = {
    "A001": 18,     # Cahiers 96 pages
    "B012": 45,     # Stylos bleus
    "C005": 32,     # Ramettes A4
    "D008": 7       # Marqueurs noirs
}

# Liste de dictionnaires : informations détaillées sur chaque produit
produits = [
    {"ref": "A001", "nom": "Cahier 96 pages",   "prix_ht": 3.50},
    {"ref": "B012", "nom": "Stylo bleu",        "prix_ht": 1.20},
    {"ref": "C005", "nom": "Ramette A4",        "prix_ht": 4.99},
    {"ref": "D008", "nom": "Marqueur noir",     "prix_ht": 2.80}
]

print("État actuel du stock :\n")

# Affichage des produits
for produit in produits:
    ref = produit["ref"]
    quantite = stock.get(ref, 0)
    print(f"{ref:<6} {produit['nom']:<22} {quantite:>4} unités   {produit['prix_ht']:>6.2f} TND")

print(f"\nNombre total d'articles différents : {len(produits)}")
print(f"Nombre total d'unités en stock      : {sum(stock.values())}")
```

**3. Exécution**

Assurez-vous que l’environnement virtuel est activé :

```bash

```
