# MiniStock – Papeterie Express

(après le chapitre 4 – Types collections)

## Objectif

Représenter plusieurs articles du stock à l’aide de **listes et de dictionnaires** et afficher les informations de base du stock de manière structurée.

---

# Notions abordées dans ce milestone

Dans cette étape du projet MiniStock, vous allez découvrir les premières **structures de données Python** permettant de représenter plusieurs éléments.

Les notions abordées sont :

- utilisation des **dictionnaires**

- utilisation des **listes**

- manipulation d’une **liste de dictionnaires**

- organisation des données d’un programme

- utilisation de **for pour parcourir une collection**

- accès aux **valeurs d’un dictionnaire**

- utilisation de **dict.get()**

- utilisation de **len()**

- utilisation de **sum()**

- affichage structuré avec **f-strings**

- séparation entre **données de produits et quantités en stock**

Cette étape permet de transformer le programme initial en une **première représentation structurée d’un stock de produits**.

# 2. Création du fichier ministock_v1.py

Créer le fichier **ministock_v1.py**

```python
# MiniStock – Papeterie Express
# Version 1 – Utilisation des collections

print("======================================")
print("   MiniStock – Papeterie Express")
print("           Version 1")
print("======================================\n")

# Dictionnaire : référence → quantité en stock
stock = {
    "A001": 18,     # Cahiers 96 pages
    "B012": 45,     # Stylos bleus
    "C005": 32,     # Ramettes A4
    "D008": 7       # Marqueurs noirs
}

# Liste de dictionnaires : description des produits
produits = [
    {"ref": "A001", "nom": "Cahier 96 pages", "prix_ht": 3.50},
    {"ref": "B012", "nom": "Stylo bleu", "prix_ht": 1.20},
    {"ref": "C005", "nom": "Ramette A4", "prix_ht": 4.99},
    {"ref": "D008", "nom": "Marqueur noir", "prix_ht": 2.80}
]

print("État actuel du stock :\n")

# Parcours de la liste des produits
for produit in produits:

    # récupérer la référence
    ref = produit["ref"]

    # récupérer la quantité
    quantite = stock.get(ref, 0)

    # affichage
    print(f"{ref:<6} {produit['nom']:<22} {quantite:>4} unités   {produit['prix_ht']:>6.2f} TND")

print(f"\nNombre total d'articles différents : {len(produits)}")
print(f"Nombre total d'unités en stock      : {sum(stock.values())}")
```

# Défi

Améliorez le programme pour afficher **la valeur totale du stock pour chaque produit**.

Formule :

valeur_stock = prix_ht × quantité

Le programme devra afficher une colonne supplémentaire :

```
A001   Cahier 96 pages           18 unités     3.50 TND   valeur: 63.00 TND
```

Puis afficher **la valeur totale du stock de la papeterie**.

---

# Solution du défi

Créer ou modifier le fichier **ministock_v1.py**

```python
# MiniStock – Papeterie Express
# Version 1 – Valeur du stock

print("======================================")
print("   MiniStock – Papeterie Express")
print("           Version 1")
print("======================================\n")

stock = {
    "A001": 18,
    "B012": 45,
    "C005": 32,
    "D008": 7
}

produits = [
    {"ref": "A001", "nom": "Cahier 96 pages", "prix_ht": 3.50},
    {"ref": "B012", "nom": "Stylo bleu", "prix_ht": 1.20},
    {"ref": "C005", "nom": "Ramette A4", "prix_ht": 4.99},
    {"ref": "D008", "nom": "Marqueur noir", "prix_ht": 2.80}
]

print("État actuel du stock :\n")

valeur_stock_total = 0

for produit in produits:

    ref = produit["ref"]
    quantite = stock.get(ref, 0)
    prix = produit["prix_ht"]

    valeur_stock = prix * quantite

    valeur_stock_total += valeur_stock

    print(f"{ref:<6} {produit['nom']:<22} {quantite:>4} unités   {prix:>6.2f} TND   valeur: {valeur_stock:>6.2f} TND")

print("\nRésumé :")
print(f"Nombre total d'articles différents : {len(produits)}")
print(f"Nombre total d'unités en stock      : {sum(stock.values())}")
print(f"Valeur totale du stock              : {valeur_stock_total:.2f} TND")
```
